## 问题记录（如实）

1. **V97 目录自指重定向**：id=10 转目录后 path 仍为 V95 的 `system/dict`，与子项 400 同 path → 目录 redirect 首叶指向自身 → 初始导航无限重定向、`#app` 不挂载（整页空白）。以 V98 前向修正（目录 path → `system/dict-manage`），已在浏览器复测挂载与两级渲染。
2. **`ToggleOn` 图标不存在**：白名单纳入种子键名时引入 `ToggleOn`，该导出在 `@element-plus/icons-vue` 不存在 → 命名导入失败、应用启动白屏。改为映射存在的 `Switch` 组件（配置键名保持 `ToggleOn` 不变）。
3. 迁移断言类失败均为链尾计数/版本锚的预期漂移，机械更新，无行为断言弱化（Phase4 数据保留/事务回滚/修复恢复断言原样保留，仅锚点 96→98、损坏样本版本 97→999）。
