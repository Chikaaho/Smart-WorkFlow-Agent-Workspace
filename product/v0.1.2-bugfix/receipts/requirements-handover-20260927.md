## V012-BUG-009 流程中心优化（4 个子需求，建议整体立项）

**现状**（/workflow/catalog）：分类仅"全部/未分类"两个 tab；流程以卡片平铺；无收藏、无常用、无最近使用；分类维护入口缺失（仅 ProcessCatalogAdmin 管理事项/分类，与流程中心展示的分类口径未打通）。

**期望**（参考蓝凌 mk.landray.com.cn 流程发起页，截图 image-20260927003740490/03938044）：

1. 布局改为「左侧分类树 + 右侧流程列表」（树带定位搜索，列表支持关键词搜索、按分类分组展示）。
2. 补齐分类维护功能（当前找不到维护入口，功能缺失）：分类 CRUD 及与流程定义的归属关系维护。
3. 收藏流程：用户级收藏（持久化）；「常用流程」= 发起次数最多的流程自动置顶，最多 5 个；收藏优先于常用。
4. 「最近使用」区：最多 5 个最近发起/办理的流程。

**涉及范围**：后端新增用户收藏表与 API、流程发起计数统计、最近使用记录（可能含 Flyway 迁移）；前端流程中心页面重构（分类树组件、收藏/常用/最近使用区块）；分类维护与 ProcessCatalogAdmin 的关系需先梳理（可能复用现有表）。建议等级：L~XL（跨前后端 + 数据模型）。

## V012-BUG-010 待办优化 + 流程主题生成规则

**现状**：待办列表无分类树；流程主题直接取用户输入，无编号规则；无申请单编号列。

**期望**（参考蓝凌"我的待办"，截图 image-20260927004212148）：待办参考蓝凌布局（分类树 + 主题/申请单编号/流程状态等列）；**管理流程时必填**在流程系统级设置中配置「流程主题生成规则」：支持字符串常量 + 时间戳（如 yymmddhhmmss 等格式）+ 自增序号等占位组合，流程发起时按规则自动生成主题/申请单编号（蓝凌示例格式：PAF2026092200001）。

**涉及范围**：后端流程定义/系统设置新增规则配置（必填校验）、发起时主题生成引擎（占位符解析：常量/时间格式/自增序号——序号需持久化与并发安全）、待办/已办列表透出新主题与单号；前端流程管理配置 UI 与列表列扩展。建议等级：L（后端业务规则 + 数据持久化）。

## V012-BUG-011 菜单 icon 配置化

**现状**：菜单 icon 由前端 `menu-icons.ts` 静态映射（名称→组件），未配置的菜单项无 icon；管理端菜单数据已有 icon 字段但无处维护。

**期望**（截图 image-20260927004357368）：icon 改为菜单管理可配置（管理后台菜单管理页提供 icon 选择器），**非必填**（未配置时使用通用默认 icon），选用通用 icon 库（如 Element Plus Icons 或引入统一图标库），前端渲染层只按菜单数据动态渲染、去掉静态映射。

**涉及范围**：菜单管理页（若无则需新建）+ icon 选择器组件 + 后端菜单 icon 字段确认（已存在则仅暴露维护入口）+ 前端 menu-icons 映射层改造与默认 icon 兜底。建议等级：M~L。

## V012-BUG-012 流程发起页优化（表单填写体验改版）

**现状**（/form/form-render/:formKey，截图 image-20260927005406275）：表单控件带边框盒子样式；页头面包屑暴露 `form_mue3nsz4` 流程标识；右侧「流程说明」卡展示表单名称/标识/模式等开发视角信息；页面嵌在布局内留白大；无流程图展示；必填与校验提示不直观。

**期望**：
1. 控件去掉组件边框线，改为常规表单「字段名称 + 输入/选择器」样式。
2. 去掉用户看不懂的流程标识（formKey 面包屑段）。
3. 删除右侧对用户是噪音的「流程说明」整卡。
4. 下方增加流程图展示。
5. 发起页改为独占整页的新页面（全屏填写），左上角仅一个简单的「< 返回」。
6. 表单与下方信息区对外边框留白仅约 2px。
7. 必填标记红色；提交/保存时在对应组件下方提示必填。
8. 用灰色底区分不可输入（只读/禁用）组件。

**涉及范围**：FormRender 8 类控件渲染样式体系改造（页型 A 规范级变更，工程宪法 §6.1）+ 页面骨架整页化 + ProcessGraphView 嵌入 + 校验提示定位。建议等级：L（表单渲染核心页型改版）。

## V012-BUG-013 流程详情页优化（与发起页同体系的只读改版）

**现状**（TaskDetail，截图 image-20260927005736155/010002218/010030286）：页头展示流程编号（UUID）；「流程变量」卡暴露 approver/recordId/formKey/tenantId/outcome 等引擎变量且 `formData` 显示 `[object Object]`；右侧流程状态卡与左侧数据表单之间大量空白；流程图节点被网格线盖住；审批意见详情弹窗直接展示 `DEFAULT_REMARK` 枚举值；标题加粗与发起页不一致；记录 tab 在 16:10 视口未撑满。

**期望**：
1. 去掉流程编号、流程变量等用户噪音信息。
2. 与发起页一致改为新开整页查看，减少留白，内容按实际填写缩放。
3. 左上角「返回」精简。
4. 表单展示组件样式与发起页统一（含标题加粗一致性）。
5. 修复流程图节点被网格线遮挡（ProcessGraphView 层级/渲染）。
6. 全站详情类展示不出现枚举值（如 `DEFAULT_REMARK`、`APPROVED`），翻译为用户语言。
7. 下方记录 tab 撑满 16:10 等宽视口。

**涉及范围**：TaskDetail 布局重构 + 表单只读渲染与发起页共用样式体系（依赖 012 的控件改版）+ ProcessGraphView 网格修复 + 枚举值翻译映射清理（含意见详情弹窗）。建议等级：L（与 012 同一设计体系，建议合并立项、012 先行）。

**可先行的小点**（若规划希望拆分）：①意见弹窗 `DEFAULT_REMARK` 枚举翻译；②流程变量 `formData`/`[object Object]` 值格式化；③流程图网格遮挡修复。三者相对独立，可提前修。
