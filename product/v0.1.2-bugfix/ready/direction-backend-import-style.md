## Owner 要求

后端代码中的全限定类名全部改为 import；开发规范中明确禁止使用全限定类名。唯一例外是同一个类中同时使用两个不同来源的同名类型，例如 Alibaba JSONObject 与 Hutool JSONObject。

## 可直接写入开发规范的条款

### Java 类型引用与 import

Java 源码引用类型时，必须使用 import 导入并以简单类名引用，禁止在代码中直接书写完整包路径的全限定类名。

唯一例外：同一类中实际同时使用来自不同包、简单类名相同的类型，造成名称冲突时，允许对冲突类型使用全限定类名以消除歧义。例如同一类同时使用 Alibaba 的 JSONObject 与 Hutool 的 JSONObject，可 import 其中一个，对另一个使用全限定类名。

例外仅限实际冲突的同名类型；不得因书写方便、临时修改、测试代码、注解或静态工具调用而使用全限定类名。只使用其中一个类型时，必须恢复 import 与简单类名引用。

本规则针对 Java 类型引用。package/import 声明自身的包路径，以及反射类名字符串、配置值和文档中的类型标识，按其语义保留，不作为类型引用机械替换。
