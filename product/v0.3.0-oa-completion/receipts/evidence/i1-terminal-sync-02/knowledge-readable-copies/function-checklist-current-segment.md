## 推荐实施顺序

**串行关键路径（Walking Skeleton）**：
`组织架构/权限(M01·M02)` → `低代码表单(M03)` → `流程引擎(M04)` → `通知(M05·M06)`  
先打通「登录 → 简单表单 → 单节点审批 → 通知」端到端最小切片，再横向铺开。

**并行轨道**（关键路径稳定后并行推进）：`AI智能助手(M07)` · `IoT(M08)` · `开放接口(M09)`。  
**横切先行**：多租户、`BaseEntity`、数据权限、Security 过滤链、字典服务须先就位。
