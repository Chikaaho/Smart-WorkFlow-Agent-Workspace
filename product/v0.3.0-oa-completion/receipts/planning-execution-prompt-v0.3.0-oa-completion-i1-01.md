## 3. 锁定项与禁止重验

禁止无依据重复：ADV 清单同步、G1a、G2a、G3a、G4、G5a、G6、G7a。已有证据指针见审查 02 §4。

只有代码修复触及相应路径时，才使受影响锁定项失效。预计 G1b 会触及 Web 组织页面，G2b 可能触及认证/租户链，G5b 会触及流程历史展示；因此只对这些路径执行聚焦行为回归，并在最终候选上运行方向要求的 Server/Web 工程门禁。V67 未修改时不重写迁移证据。

## 4. 对象与生命周期

- 保留 `identity.txt` 中三仓 HEAD，并为最终工作树生成新指纹。
- 优先复用审查表指定对象；对象已终结或清理时，必须建立旧 ID→新 ID 映射，不得隐式换对象。
- 新场景先记录用户、租户、实例、任务、数据库和 token 非敏感指纹，再执行变更；证据完成后才清理。
- 清理只限定本轮对象，并提供清理后回读。不得重建另一数据库证明原运行库零残留。
