## 三、已锁定项与禁止重验

5. GraalJS/Java 子进程沙箱测试类与当前后端全量测试；后端代码变更触及时才按工程门禁重跑。

## 七、证据包与回执格式

每项只在回执写四要素，原始流单独入附件：

`原子 ID → 原始文件/位置 → 实际结果 → 覆盖边界`

附件必须包含工作目录、时间、对象 ID、实际命令/请求、原始响应、退出码；HTTP 状态与业务 code 同时记录。清单和哈希由工具生成并回读，校验文件排除自身。证据层级如实写为单测、集成运行、真实 API/SQL、真实 MQTT 或真实浏览器，不互相改名。
