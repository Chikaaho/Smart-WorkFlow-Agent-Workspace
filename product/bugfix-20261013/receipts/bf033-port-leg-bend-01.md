# BF20261013-033 执行回执：端口固定 + 端口旁固定小段（拖端口腿生成折，竖线随横线变短）

2026-10-14｜执行者提交（fix-loop 持续修复批次）；Owner 原反馈 2026-10-14 文字（端口不应整体移动 / 端口旁一小段固定）+ WPS 参考截图 2 张，并补充「上横线下拉 → 竖线变短」。

## 问题与口径修正

BF032 的实现是「拖端口腿 = 端口沿节点边框滑动」，Owner 明确否决：**移动时端口不应整体移动，端口旁一小段是固定的**（WPS 参考截图即此形态）。同时补充了几何预期：把上横线往下拉 → 竖线变短。

BF032 的滑动实现已**全量移除**（`config.sourceOffset/targetOffset`、`setEdgePortOffset`、`edgePortSlideSpan/portSlideCoordinate/portSlideOffset`、`portPoint(offset)`、`edgeEndpoints(offsets)`），未产生任何落库数据（服务端 graph_json 复核无 offset 键）。

## 修复

1. **端口腿拖动 = 端口固定 + 生成折**（`portLegDragPoints`，`EDGE_PORT_STUB=24`）：端口坐标不变；端口旁保留 24px 固定小段；折段与「被拖段」移到指针坐标；折长不足最小段长时按拖动方向推离端口；源/目标两侧对称。因此「上横线下拉」时中间竖线随之变短。
2. **固定小段不给手柄**（`EDGE_STUB_HANDLE_MIN=32`）：端口腿短于该长度不再显示手柄（与 WPS 一致：端口旁固定段不可拖）。
3. **折可逆**：内段拖动移除「推离相邻段坐标」规则——把被拖段拖回端口所在坐标时，折段长度归零、归一自动折叠，形状还原（用例断言）。
4. **段数上限 5→12**：拖端口腿会逐次加折（正常使用远达不到 12）；超过才按端口朝向重建，仅作历史异常数据兜底，不再压平用户形状。
