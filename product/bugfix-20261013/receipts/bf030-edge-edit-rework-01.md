## ①点击选中线后再次点击线会改变角度（返工）

- 旧行为：连线按下在「已选中」分支按点击点**插入拐点并立即写模型**，因此第二次点击（甚至轻微抖动）就会改变角度；拐点随后可自由拖动，形状可任意漂移。
- 新行为：**点击 = 仅选中**。未选中 → 只选中；已选中 → 只进入「端点改接 / 内段拖动」会话，且**指针移动不足 3px（armed 阈值）不改任何形状**；端点改接同样要求真实拖动（armed）才提交，纯点击零写入。
- 验证：同一连线连点两次，path 与段数完全不变、脏标记保持空、`.el-message`=0。

## ②内段手柄 + 方向光标

- 选中连线时在**内段中点**显示实心方块手柄（首尾端口腿不可拖、不显示）；**垂直段左右拖（ew-resize）**、**水平段上下拖（ns-resize）**。
- **悬停连线内段本身**也按同一轴向展示方向光标（不必精确压住手柄即可拖动）；端口腿与端点区域保持 pointer / grab。
- 验证：审批→END（水平内段）手柄与悬停光标 ns-resize；START→审批（垂直内段）手柄与悬停光标 ew-resize。

## ③约束：严格横平竖直 / 不重叠 / 不贪吃蛇

- **严格横平竖直**：拖动只改变内段自身的一个坐标 → 所有线段恒为轴对齐（适配器用例对全量取值区间断言每段轴对齐）。
- **不重叠**：折线写入前归一（去重合点 + 折叠共线中点）——归一后平行段坐标互不相同，任意两段不可能共线重叠（用例断言任意两段不共线）。
- **不贪吃蛇**：连线最多 3 段（`EDGE_MAX_SEGMENTS`）；超出（历史点击插入的产物）按端口朝向重建 3 段 Z、偏移取折线包围盒中心并夹取净空；端口对齐退化为直线、两端朝向不同退化为 L。`normalizeGraph`/`setEdgeWaypoints` 写入前收敛，模型与渲染同源（落库即收敛结果）。
- **拖动夹取**：内段移动时两条相邻段保持原方向且不短于 `EDGE_MIN_SEGMENT=20`——端口腿因此不会反向穿入节点、不会与边框平行贴边；无可行区间时原样不动（不产生退化形状）。
- 验证（实景）：水平内段拖 y=300/150/252 → 255（=终点端口 275-20）/225（=起点端口 205+20）/252；垂直内段拖 x=150/400/300 → 200（=180+20）/320（=340-20）/300；每步 3 段、全轴对齐、无重叠。
- 附带修正：画布空白处按下与模型 selection 同口径**取消选中**（此前视觉选中态残留、连线手柄不消失）。
