## ②脚本输入框 JS 标准样式（着色 + 关键字提示 + 自动补齐）

- 新组件 `JsCodeEditor`（无第三方依赖，CSP 安全）：透明 textarea 叠在着色层之上（同字体度量、滚动同步）。
  - **着色**：关键字（var/if/return/…品红）、字面量（true/false/null/undefined 蓝）、内置对象与常用方法（teal）、`#函数名` 语法糖（紫）、字符串（绿）、数字（蓝）、注释（灰斜体）——对齐浏览器 console 观感。
  - **自动补齐**：输入时按光标处前缀弹候选（目录函数 + 关键字 + 字面量 + 内置对象），**Tab/Enter 补齐**、上下键选择、Esc 关闭；无候选时 Tab 插入两空格；候选框按光标位置定位。
- 接入统一脚本弹窗（ScriptDialog）——流程脚本（触发器/节点触发器/子流程判断/初始值/审批人表达式）与表单字段脚本共用同一编辑器。
- 验证：输入 `re` 光标处弹出 return/RegExp/reduce，Tab 补齐生效（截图 bf028-editor-highlight.png）。

## ③模拟运行（Owner 追加）

- 脚本弹窗新增「模拟运行」：**纯前端**用既有脚本解释器（与表单脚本运行时同一实现，CSP 禁 eval 下不生成真实函数）执行 `#语法糖编译 + 解释器解析` 后的脚本，展示：
  - **返回值**；**调用记录**（获取类返回示例值：流程变量/字段值 → `示例值(变量名)`，用户/部门类 → `1001`，当前用户姓名 → `示例用户`；设置类/提示类 → 记录调用并返回 null）；**语法/运行错误**（含解释器诊断信息，红色）。
- 明确边界：模拟运行在本地执行、不落库、不调用服务端；获取类为示例值（真实值运行时由服务端按变量来源解析）——面板文案与回执均如实标注。
- 验证：脚本 `var v = #获取流程变量(var_dept_ids); #设置流程变量(var_result, v); return v ? 1 : 0;` 模拟运行 → 返回值 1，调用记录两条（截图 bf028-sim-run.png）。
