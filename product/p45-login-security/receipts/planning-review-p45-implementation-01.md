## 1. 结论

`FAILED`。功能保持 `VERIFYING`，不得核销 P45、晋级 M02-F06-01、移动主方向或写 `PASSED/COMPLETED`。

回执证明执行层已经形成完整实现面，并报告了定向测试、全量测试、HTTP 与浏览器验证；但多项安全语义与行为证据尚不足以支持功能通过。本结论不否定已提交实现，只要求在同一方向内完成下列修正和补证。

## 2. 已锁定项

- A1：现有 access 内存 + refresh HttpOnly Cookie 的双 Token 职责保持不变。
- A2：执行层未提前核销 P45、晋级 M02-F06-01 或写功能终态，方向 §7-13 通过。
- A3：登录挑战、RSA、错误码、Cookie Path 配置和前端恢复入口的文件范围已披露；后续只修正剩余行为，不要求重复编写结构清单。

除 A1-A3 外，其余标准尚未锁定为通过。后续回执不得把类名、测试名或汇总数字替代原始行为证据。

## 3. 剩余缺口矩阵

| 缺口 | 失败事实 | 当前证据为何不足 | 通过条件 |
|---|---|---|---|
| G1 验证码有效性 | 回执说明验证码是“四位文本直接在挑战响应中展示” | 自动客户端可直接读取答案并原样提交，不能构成人机验证码 | 挑战响应提供可渲染验证码载荷且不包含独立答案字段、文本节点或可直接读取的答案元数据；真实请求证明答案只由用户输入进入登录请求 |
| G2 过期语义 | 回执同时声称 Redis TTL=300 秒，并要求超过 5 分钟返回 2102 | 记录在 300 秒删除后无法验证“内容正确但已过期”，通常会落入 2101；测试替身不能证明真实 Redis 语义 | 分离 300 秒业务有效期与记录保留期；真实 Redis 中证明 5 分钟内有效、超过 5 分钟且记录仍可判别时返回 2102、保留期结束后按无记录处理 |
| G3 原子并发 | 回执仅写“DEL 原子消费”和第二次重放 2101 | 顺序重放不等于并发；类/命令原子也未证明整条认证链只有一次进入 | 在真实 Redis 上并发提交同一挑战，原始结果证明最多一个请求进入密码认证/签发 Token，其余无副作用；提供并发数、逐结果和总计 |
| G4 密钥轮换 | 回执明确承认未做轮换端到端场景 | 未证明旧挑战在重叠窗口可用、退役后拒绝，也未证明新挑战绑定新版本 | 提供当前/上一版本并存、新挑战使用当前版本、旧挑战在窗口内成功、退役或保留期后失败的正反向行为证据 |
| G5 Cookie 生产前缀 | 浏览器只验证 `/api` 开发前缀；`/sw-server/api` 仅配置和单元断言 | 方向要求等价公开前缀环境；单元断言不能证明浏览器 Path 匹配、Cookie 携带和 F5 恢复 | 在真实浏览器或等价公开前缀 `/sw-server/api` 环境完成修改前/后链路，保留 Set-Cookie、Cookie 存储、refresh 请求、响应、F5、深链和退出证据 |
| G6 用户/租户隔离 | 回执以“UUID 独立”和既有撤销语义代替行为证据 | 随机标识不证明服务端挑战、Cookie、session 和路由不会串用 | 至少两个用户和两个租户执行交叉挑战、错误复用、登录恢复与退出，证明身份、租户、Cookie 和 Redis 状态不串用 |
| G7 原始验证输出 | 回执只有命令与汇总表，没有可读原始输出或附件 | 按规划验收规则，汇总属于声明证据；1952 与正式基线 955、V46 与正式 V44 差异过大且未勾稽 | 追加原始命令输出摘要/附件路径、退出码、逐模块叶子计数及前后端完整计数；解释每项增量来源，禁止推算或重复统计 |
| G8 输入与分支行为 | 2101-2104、缺失字段、错误版本、状态拒绝等主要来自测试名和摘要 | 尚未提供请求/响应原文、后续调用零执行和真实 Redis 状态变化 | 每个分支提供脱敏请求、响应、状态码/业务码、挑战消费状态和后续校验零执行证据；敏感值不得进入回执 |
| G9 敏感信息反向检查 | 只写 grep/Redis“零命中”摘要 | 没有命令范围、输出和字段清单，不能确认覆盖日志、响应、Cookie、Redis 与前端存储 | 提供脱敏命令、搜索范围、零命中输出及浏览器存储矩阵；不得输出真实密码、私钥、Token 或验证码答案 |
| G10 基线与迁移漂移 | P45 未声明迁移，却把 Flyway 断言从 V44 调到 V46，并称为分支历史 | 当前正式摘要仍是 V44；未披露 V45/V46 内容、来源、状态及与 P45 输入提交关系 | 提供前后端 branch/HEAD、工作树状态、P45 精确 diff 基线；列明 V45/V46 文件、提交和授权状态。若不属于已接受输入，不得用修改测试断言掩盖漂移 |
