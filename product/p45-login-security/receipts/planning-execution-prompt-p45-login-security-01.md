## 3. 已锁定且禁止重验

- access 内存 + refresh HttpOnly Cookie 双 Token 职责。
- 执行层终态纪律和已披露文件范围。
- 验证码业务有效期 300 秒、记录保留期 600 秒及三段过期行为。
- 光栅验证码载荷方向。
- 登录请求不新增租户选择；租户继续由认证成功账号派生。

## 4. 允许范围

### 允许读取

- P45 主方向、补充方向、两次规划审查和现有执行回执。
- 后端登录挑战、RSA、Cookie、Redis、认证用户/租户派生、相关配置和测试。
- 前端登录、认证、请求、守卫、权限路由、相关测试与生产构建配置。
- `knowledge/current-status.md`、迁移文件与 git 历史，仅用于 H6 对账。

### 允许修改

- H1 必需的登录挑战摘要实现、配置和对应测试。
- H2-H5 直接需要的测试/证据辅助资产；不得改变业务目标来制造通过结果。
- `product/p45-login-security/receipts/evidence-p45-supplement-01/` 中含敏感值或不可复跑的证据脚本，可进行安全清理和依赖补全；必须在新回执中列出实际处理。
- 新建一份增量补充回执和新的安全证据目录。

### 允许命令

- 只读 git/status/log/diff、迁移与权威状态核对。
- P45 定向测试、前后端受影响测试、后端全量、前端 typecheck/lint/test/build。
- 启动等价证据环境、真实 Redis、真实浏览器检查及只读数据库计数。
- 敏感信息扫描；扫描表达式不得包含真实敏感值。

## 5. 执行顺序

1. 先清理证据脚本的敏感值与输出路径；如需轮换凭据先完成轮换。
2. 完成 H1，并证明 Redis 记录不能独立恢复答案。
3. 在同一固定输入版本完成 H2-H5 行为包。
4. 完成 H6 全量与基线对账，所有计数从原始输出机械聚合。
5. 执行 H7 扫描；扫描未通过不得提交回执。
6. 新建增量回执，只提交 H1-H7，不复述已锁定项。

## 6. 相对上一版新增或收紧约束

- 验证码摘要必须使用服务端密钥认证，证据环境不再允许从 Redis 摘要离线恢复答案。
- 浏览器、全量测试、数据库和 git 结论必须具有实际附件，回执表格不再视为原始证据。
- 所有证据脚本纳入敏感信息验收面，禁止硬编码或打印凭据、答案和完整认证材料。
- 双租户要求收敛为当前支持的账号派生租户语义，不扩大登录契约。

## 7. 逐缺口证据包格式

每个 H 编号单独包含：

1. 固定输入版本与命令。
2. 行为输出附件路径和退出码。
3. 正向目标断言。
4. 反向零残留断言。
5. 结论 `PASS` 或 `BLOCKED`。

浏览器证据至少包括页面截图和脱敏网络摘要；测试证据至少包括命令输出尾部、退出码和机械计数；数据库证据只报告行数/身份 ID 摘要，不导出 Token 或 Cookie。
