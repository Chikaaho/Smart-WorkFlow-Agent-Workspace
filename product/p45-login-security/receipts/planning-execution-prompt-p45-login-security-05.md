## 3. 锁定项与禁止事项

- 锁定 H1、A/B、L3-P、N1、N2、N3 行为和 N4。
- 禁止运行后端或前端测试、启动业务服务、重做浏览器行为、修改生产代码或迁移。
- 禁止修改方向、历史规划审查、需求池、memory、正式状态和正式基线。
- 禁止在任何新文件中记录被清理的具体凭据或验证码字符。
- 只允许修改敏感证据附件、N5/O1 安全扫描脚本，并新增 O1 固定证据包和一份增量执行回执。

## 4. 固定证据包

目录：`product/p45-login-security/receipts/evidence-p45-o1/`

固定附件：

- `o1-cleanup-manifest.json`
- `o1-image-checks.json`
- `o1-enumeration.json`
- `o1-security-scan.json`
- `o1-security-scan.mjs`
- `o1-command.txt`

### 4.1 清理清单

记录每个实际处理路径、处理类型、处理前 SHA-256、处理后 SHA-256、当前状态。只使用 `<REDACTED>` 等固定占位符，不写原值。修改前截图必须保留失败路由和登录页语义，同时将验证码区域像素级覆盖；清单注明覆盖矩形和不可逆导出结果。

### 4.2 图片检查

枚举整个回执树内全部图片，逐张记录路径、SHA-256、实际编码、尺寸、OCR/视觉检查方法及敏感发现数。验证码区域已遮挡的图片必须给出 `captchaReadable=false`；检查附件不得转录识别出的字符。

### 4.3 文本与脚本扫描

扫描全部文本、日志、JSON、Markdown 和脚本。规则至少覆盖：

- 私钥和密钥材料；
- 密码、默认密码、测试密码等赋值或自然语言值；
- 验证码答案、验证码字符及答案型输出；
- access/refresh Token、JWT、Bearer、完整 Cookie；
- 脚本中的敏感输出路径与硬编码凭据。

对扫描器自身只允许按规则 ID、行号和源码哈希精确豁免规则字面量；不得跳过整文件。先用受限临时夹具证明每类规则能检出，再删除夹具，最终扫描必须零发现。

### 4.4 全树勾稽

`o1-enumeration.json` 枚举最终回执树全部路径。文本扫描路径、脚本检查路径、图片检查路径及其他二进制检查路径的并集必须等于枚举全集，每个路径恰出现一次。`o1-security-scan.json` 必须显式包含：

- `enumeratedTotal`
- 各分类检查数
- `unionCheck=true`
- `duplicatePathCount=0`
- `uninspectedPaths=[]`
- `findingCount=0`
- `verdict="PASS"`

### 4.5 命令附件

`o1-command.txt` 记录实际清理后枚举命令、扫描器语法检查、规则正向检出回归、最终扫描和文件总数复核；每个命令均包含原始摘要与 Shell 实际退出码。

最终扫描采用确定性两遍运行：所有附件和增量回执先定稿；第一遍生成扫描结果，第二遍在相同输入上扫描第一遍结果并覆盖为字节一致结果。两遍 SHA-256 必须相同，第二遍退出码为 0，之后不得再修改回执树。

## 5. 正反向断言

正向目标：已知两类残留均已安全化；规则临时夹具能够逐类检出；最终全树枚举与检查路径全集一致；确定性两遍扫描结果一致且显式 `PASS`。

零残留目标：全回执树零明文凭据、零可辨识验证码答案、零私钥、零 access/refresh Token、零完整 Cookie；零未检查路径；零扫描器整文件豁免；零锁定行为重验。
