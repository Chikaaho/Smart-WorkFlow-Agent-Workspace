# P45 增量证据包 02

本目录只承载本轮 H1-H7 的新增证据工具与脱敏结果。测试账号、密码、验证码、RSA 私钥、摘要密钥、Token 和完整 Cookie 均不进入脚本参数、输出或文件；需要输入时由进程环境注入，输出只保留状态、计数、字段名和存在性。

## 工具

- `h1-enumerate.mjs`：读取 Redis 记录字段并在无服务端密钥条件下执行反向检查。
- `h2-concurrent.mjs`：真实认证服务上的同一挑战 8 路并发；凭据由环境注入。
- `h5-cross.mjs`：双账号正常/交叉挑战提交；身份和租户由外部只读数据库查询对账。
- `h3-rotation-map.mjs`：校验当前、重叠、退役三阶段脱敏清单。
- `h6-surefire.mjs`：按 XML 文件机械聚合后端测试计数。
- `h6-baseline.mjs`：读取仓库 branch、HEAD、脱敏工作树状态、diff-stat 和迁移版本。
- `h7-security-scan.mjs`：扫描本目录的通用敏感值形态。

## 证据边界

当前环境已取得 H1、后端定向测试、H6 和 H7 结果。H3 轮换、H4 登录态浏览器链、H2 真实并发认证和 H5 双账号链需要外部密钥/账号输入；缺失时保持 `BLOCKED`，不使用静态或 Mock 结果替代。
