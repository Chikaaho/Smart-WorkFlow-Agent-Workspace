# 工作区 Git 原始证据清理任务

## 授权与目标

Owner 于 2026-10-08 授权本次同时按执行与管理员职责处理：删除根仓已提交的日志和原始证据，使任务与回执文档继续留在 Git，证据附件留在本机；补充项目开发规范与各仓忽略规则。

## 范围

- 根仓目标分支：`origin/develop-sw`。移除该分支历史中路径包含 `evidence/` 的原始证据附件及所有 `*.log`、`*.log.gz` 文件；保留证据目录之外的任务、方向、回执 Markdown、源码和测试基线。
- Web 与 Server 的 `develop` 分支：只更新工程规范与日志忽略规则，不改业务源码、测试源码或回归基线。
- 工作区当前本地证据不物理删除；由 `.gitignore` 排除，不提交。

## 验收条件

1. 根仓 `develop-sw` 的新历史中不再包含原始证据目录内容或日志对象；任务与回执 Markdown 保留。
2. 根项目说明、前后端工程宪法及三个仓库的 `.gitignore` 明确证据与日志不入库。
3. 更新远端前复核 `origin/develop-sw` 当前 SHA。历史改写及强制推送完成后，重新检查可达历史并回读远端 SHA。

## 操作边界

根仓历史改写会改变 `develop-sw` 上已有提交 SHA。远端改写和强制推送前需向 Owner 说明分支、删除范围与协作者同步影响，并取得对此具体动作的明确授权；`main`、前后端业务分支不做历史改写。
