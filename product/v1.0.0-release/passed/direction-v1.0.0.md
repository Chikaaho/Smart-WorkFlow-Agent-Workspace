## 1. 功能范围与验收标准

### F1 人员批量导入导出（P27）

| ID | 验收标准 |
|---|---|
| F1-1 模板 | 用户管理页可下载导入模板，格式与表单数据导入一致（xlsx、带模板签名）。模板列至少有：账号、姓名、手机、邮箱、部门编码、岗位编码、角色编码、状态，**没有密码列**。用旧模板或别的模板导入时整体拒绝 |
| F1-2 导入 | 导入时管理员填一个初始密码，所有导入行都用它。部门、岗位、角色按**编码**匹配：0 条或多条命中都报行级错误，写明哪一行、哪一列、原因。账号已存在、文件内重复、必填缺失都报行级错误。**有任何一行出错就整批不入库**。上限与表单导入一致（500 行/5MB） |
| F1-3 导出 | 按当前列表筛选条件导出，列与模板一致（加部门名称等可读列），可以直接改了再导入。**不导出密码**；导出受数据权限约束 |
| F1-4 首次改密 | 导入的用户、管理员新建的用户首次登录都必须改密：登录后只能进改密页，**服务端**拒绝其他业务接口（不能只做前端跳转）。新密码至少 8 位，且不能等于初始密码。改完正常使用。现有用户、SSO 登录不受影响 |
| F1-5 权限 | 新增导入、导出两个权限点和按钮，菜单种子 9 种数据库都写，并授权给管理员角色（`sys_role_menu`，见 P24）。没有权限的账号看不到按钮，直接调接口返回 403 |
| F1-6 租户 | 租户管理员只能导入导出本租户的人员；超管跨租户导入时必须明确指定目标租户，不能落到默认租户 |

已知限制，不在本次修：手机号没有唯一约束。导入时文件内手机号重复报错；和库里已有手机号重复时只给警告、不拦截，回执说明处理方式。

### F2 打印模板（P33）

| ID | 验收标准 |
|---|---|
| F2-1 模板配置 | 表单设计器里可以配置打印模板：选择打印哪些字段、明细表、审批历史，配置抬头和页眉页脚。模板随表单定义一起版本化。不配置时按默认模板打印（全部可见字段 + 明细表 + 审批历史） |
| F2-2 浏览器打印 | 表单详情、任务详情、「我发起的」实例详情都有「打印」按钮，点了出打印预览：A4、中文正常，不带菜单和按钮，分页时明细表表头重复、行不被截断。审批历史带意见摘要和部门 |
| F2-3 服务端 PDF | 同样三处可以下载 PDF，内容与浏览器打印一致，中文字体随产物打包，字体许可证可开源分发（例如 Noto Sans SC，OFL）。演示服务器不需要另装字体 |
| F2-4 权限 | 打印和 PDF 只输出当前用户在详情页能看到的内容，字段级隐藏照样生效。服务端 PDF 走有权限过滤的读取链路，**不得**使用无权限过滤的内部读取接口 |
| F2-5 版本 | 已提交的历史实例按提交时的表单版本打印；如果确实定位不到版本，按当前版本打印，并在页脚注明，回执写明哪些情况会这样 |
| F2-6 明细表导出 Excel | 表单里的明细表组件，在表单详情、任务详情、「我发起的」实例详情的只读视图中都有「导出 Excel」按钮，导出这一张明细表的全部行（不受页面分页影响）。列头用字段显示名，值用显示值（人员、部门、选项、日期 `yyyy-MM-dd HH:mm`、多选用顿号分隔），不输出内部 id。字段级隐藏同样生效，导出内容与页面一致。带公式注入防护（同表单数据导入导出）。文件名包含表单名、明细表名、记录编号。一个表单里有多张明细表时，每张表单独导出 |

### F3 日志查询（P40）

| ID | 验收标准 |
|---|---|
| F3-1 登录日志 | 登录成功、登录失败（各种失败原因都要记）、登出、改密都有记录：时间、账号、租户、结果、失败原因、IP、浏览器信息 |
| F3-2 操作日志 | 用户、角色、部门、岗位、菜单、字典、租户、流程定义、表单定义的增删改，以及 F1 导入导出，都有记录：时间、操作人、模块、动作、对象、结果。记录里**不得**出现密码、令牌、密钥 |
| F3-3 异常日志 | 服务端未处理异常（5xx）有记录：时间、接口、操作人、异常类型、摘要、追踪号；不记完整堆栈和请求体 |
| F3-4 查询页 | 系统管理下新增「日志查询」，分登录、操作、异常三个页签，可按时间、用户、模块、结果、IP 筛选和分页。租户管理员只看本租户，超管可按租户筛选。有独立的菜单权限 |
| F3-5 不影响业务 | 写日志失败时业务照常完成；登录失败的记录不能因为登录被拒而丢失 |
| F3-6 保留 | 默认保留 90 天，可配置；每天自动清理过期记录；查询按时间有索引 |
