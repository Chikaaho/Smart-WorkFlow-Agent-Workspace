必须按以下顺序闭环：

1. 建立 G1—G9 的自动化行为验证或等价可复现真实环境；
2. 修复验证暴露的 P32 范围内问题；
3. 逐缺口执行固定输入/命令并保存原始结果；

## 6. 逐缺口证据包格式

每个 G 编号单独提交以下五项，缺一即未核销：

1. `输入`：固定文件、数据、身份、请求参数或前置状态；
2. `命令/动作`：可复现的单一命令或真实页面操作；
3. `原始结果`：关键响应、文件解析值、数据库前后值、最终路由/组件或进程退出码；
4. `正向断言`：本场景必须出现什么；
5. `零残留断言`：不得出现什么，失败场景必须包含数据/权限/旧状态零残留。
