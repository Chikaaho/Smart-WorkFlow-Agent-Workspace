## 1. 权威输入

仅使用：正式方向、`planning-rereview-v2-20260828.md`、本提示、终态机器契约和公共 Validator。L1—L6 已锁定，禁止重验；历史实现回执仅作事实背景，不得作为本轮证据。

## 2. 允许范围

仅允许修改 P32 直接相关后端实现/测试、因 v5 路由改动必须验证的表单控制器测试、前端 `src/modules/form/` 的 P32 API/视图/测试、P32 Mock handler/测试、必要依赖配置和本功能追加回执。禁止修改正式方向、memory、knowledge、需求池、清单、其他业务模块和历史回执。R2 无法满足时只允许 `BLOCKED`。

## 3. 独立证据包

### R1 模板失效与公式安全

- V1 模板在表单字段结构变更并发布 V2 后必须被拒绝、提示重下，数据库零新增。
- 以 `= + - @` 开头的业务文本经导入和导出后仍为文本，不得成为公式或外部链接。
- 原始输出必须含请求状态/错误、单元格类型和值、导入前后计数。

### R2 字段矩阵与 REFERENCE

- 列出当前单条新增契约允许的全部字段类型，每种给出“支持/明确不适用/阻塞”单值。
- 真实 REFERENCE 导入必须存稳定 id，查询/导出显示业务值；不存在或跨租户 id 拒绝且零写入。
- 不得静默丢列或把显示文本当 id。TABLE/RICH_TEXT 若属当前可录入契约但无法保持方向语义，必须 `BLOCKED`。

### R3 拒绝矩阵

分别提交非 `.xlsx`、损坏工作簿、映射行篡改、必填缺失、类型错误、非法选项、非法/越权关联、更新/覆盖意图的固定输入、精确错误、行/字段定位和导入前后快照。全部场景零新增、零更新；不得用 L4 替代。

### R4 筛选、租户、数据权限和关联导出

固定数据至少覆盖两个租户、同租户两组可区分权限的数据和 REFERENCE。提交授权、受限、跨租户身份的筛选参数和解析后文件逐行值；文件中必须无筛选外、权限外、跨租户记录及内部字段。

### R5 三种上限

文件字节、导入行数、导出结果必须各有单一上限。提交文件大小恰好上限/超一单位、500/501 行、导出请求 1001 且数据超过 1000 的实际行为；报告导入前后计数和导出实际数据行数。源码或“已钳制”不计。

### R6 三身份页面与请求链

固定为无 P32 权限普通用户、有 P32 权限用户、未登录用户。逐个记录起始/最终 URL、组件挂载或拒绝、三个按钮状态、一次真实操作请求和后端响应。授权身份实际下载模板并导出；其他两种身份须由页面与后端共同拒绝。

### R7 Mock/真实语义

同一输入分别走 Mock 与真实后端：模板成功、合法导入、格式错、字段校验错、权限拒绝、空集导出。逐字段比较 HTTP 状态、业务码、结构、错误定位、文件类型/表头；URL 一致不计。

### R8 路由回归与最终门禁

- v5 修改的 6 个控制器逐一证明表单定义、保存/发布、提交、查询、编辑、删除、模板/导入/导出均为单一 `/api` 前缀且无 `/api/api` 残留。
- 新增后端测试承接 R1—R5；新增前端/Mock 测试承接 R6—R7 可自动化部分，必须提供实际输出与精确计数。
- 固定命令顺序：
  1. `ps aux | grep -E '(mvn|pnpm|npm|node.*(vite|vitest|vue-tsc))' | grep -v grep`
  2. 后端根：`MAVEN_OPTS="-Xmx2g" mvn test`
  3. 再次互斥检测，确认无 Maven 后进入前端
  4. `NODE_OPTIONS="--max-old-space-size=2048" pnpm typecheck`
  5. `NODE_OPTIONS="--max-old-space-size=2048" pnpm lint`
  6. `NODE_OPTIONS="--max-old-space-size=2048" pnpm test`
  7. `NODE_OPTIONS="--max-old-space-size=2048" pnpm build`
- 每条报告退出码、精确测试文件/用例计数和构建结果。

### R9 合法执行终态

读取当前契约，生成规划验收前允许的执行状态，禁止 `COMPLETED`；把末行 JSON 实际送入公共 Validator，提交末行、命令、退出码和输出。
