# B021-022 执行回执（第 1 轮）

日期：2026-11-03。Owner 截图：表单设计器「流程设计」页签渲染了关联流程列表（一行流程 +
筛选栏），重申「一个表单只有一个或者没有流程，不要流程列表」。

## 1. 定位

- 既有逻辑只在「点击页签切换」时单流程直达画布（`enterProcessCanvasIfSingle`，
  total!==1 不跳）；直链/刷新落在 `?tab=processes`、或前进后退切到该页签时不走跳转，
  RelatedProcessesPanel 列表照常渲染——同一页签两种形态，即截图中的列表。
- 契约本就是 0/1 流程：0 个由 UnconfiguredFlowBoard 空态画布承接（新建入口在板内），
  列表壳对 1 个流程的场景纯属多余。

## 2. 修改（Web `d57ccf9`，2 文件，已推送）

- `FormDesigner.vue`：
  - `enterProcessCanvasIfSingle` 条件 `total !== 1` → `total < 1`（契约 0/1；异常多流取首个）。
  - `activeTab` watcher 统一补跳（页签点击/前进后退同路径）；`onTabChange` 里的显式调用删除。
  - `loadForm` 完成钩子：初始页签即流程设计时补跳——直链/刷新不再闪现列表。
- spec +2：直链 `?tab=processes` 直达画布；零流程停留页签由空态承接（不渲染列表壳）。

## 3. 验证

- 门禁：typecheck 0 / lint 0 / 1996 通过 3 跳过 / build 5.48s。
- 实机（IAB）：「测试」表单（1 个流程）点流程设计页签 → 直达
  `/workflow/defs/:id/design` 画布，无列表；直链
  `/form/designer/:id?tab=processes` 打开 → 同样直达画布，页面无「流程名称」列表文案。

## 4. 待验收

- 任一表单流程设计页签：有流程直接进画布，无流程显示空态画布（新建入口在板内），任何路径都不再出现流程列表。
