# B021-018 执行回执（第 1 轮）

日期：2026-11-03。Owner 截图：表单设计器画布「单行文本 *」必填星号为深色，
指出必填标记应为红色。

## 1. 定位

- 画布设计态的必填星号由 `src/adapters/form-designer/FormPreview.vue` 的
  `.fc-host--design .el-form-item.is-required .el-form-item__label::after` 渲染，
  颜色写死 `#344164`（0.2.0 p53 `29d90e8` 按当时设计稿节点07落的深色），与全站其它
  必填标记（弹窗表单 `form-field--required`、`ws-dialog-field__label--required`、
  运行态 `DynamicField`、任务详情 `required-mark`、预览弹窗 `preview-modal__star`）
  一律 `--sw-danger` 红色不一致。
- 全局检索 `content: '*'` 前置 color 规则：仅此一处非红。

## 2. 修改（Web `edba53a`，1 文件，已推送）

- `FormPreview.vue`：星号颜色 `#344164` → `var(--sw-danger)`；位置（标签后、前置星隐藏）
  不变。

## 3. 验证

- 门禁：typecheck 0 / lint 0 / 1993 通过 3 跳过 / build 4.30s。
- 实机（IAB）：新建表单设计器 → 组件库点「单行文本」→ 属性面板勾选「是否必填」→ 画布
  标签 `::after` content `"*"`、color `rgb(229, 72, 77)`（= `--sw-danger #e5484d`），
  `::before` display none；截图星号红色。

## 4. 待验收

- 任一表单设计器画布，勾选字段必填后标签尾部星号为红色。
