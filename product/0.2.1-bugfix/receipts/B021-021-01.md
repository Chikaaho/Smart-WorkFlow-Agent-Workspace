# B021-021 执行回执（第 1 轮）

日期：2026-11-03。Owner 截图：用户端应用中心（工作台区）应用内页目录树上出现
编辑/新建表单/删除管理菜单，指示首页进的应用不应看到操作栏。

## 1. 定位

- 目录树是管理端 `AppWorkspace` 与用户端 `AppCenterDetail` 共用的 `AppTreeNav`，
  管理菜单仅按 `hasPerm('form:app:manage')` 显隐——admin 同时进入两端，权限为真导致
  用户端视图也渲染管理动作。菜单是「视图属性」而非「权限缺口」：用户端视图本就不该有
  管理动作（服务端 `app-center` 接口也只读）。

## 2. 修改（Web `1e2ab65`，3 文件，已推送）

- `AppTreeNav.vue`：新增 `manageable` prop（缺省 false），`canManage = manageable &&
  hasPerm('form:app:manage')`；三处管理菜单（目录更多/表单更多/页脚新建族）统一受其门禁。
- `AppWorkspace.vue`（管理端工作台）显式传 `manageable`；`AppCenterDetail.vue`（用户端）
  不传，恒无管理菜单。

## 3. 验证

- 门禁：typecheck 0 / lint 0 / 1994 通过 3 跳过 / build 4.55s（AppTreeNav.spec +2：缺省
  manageable 即便有权限不渲染菜单；manageable+权限照常渲染）。
- 实机（IAB，admin）：应用中心应用内页 `dir-more/form-more` 触发点 0、右键目录无菜单；
  管理端 `/form/app-manage/:appId` 工作台菜单触发点 2，回归正常。

## 4. 待验收

- 应用中心（工作台区）任一应用内页目录树无 编辑/新建表单/删除；管理端应用管理工作台不受影响。
