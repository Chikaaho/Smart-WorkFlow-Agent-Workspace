# B021-001 执行回执（第 1 轮）

日期：2026-10-31。对象：工作台首页误渲染「← 返回」按钮。等级：S（局部 UI 条件渲染，不改业务逻辑与契约）。

## 1. 问题与复现

- 复现：登录后直达或经顶栏进入 `/workspace`，查看态二级工具栏左上角出现「← 返回」；点击 `goBackFromView` 无应用内历史时执行 `router.push('/workspace')`，把首页再压入历史，无实际回跳意义。Owner 截图红框标注。
- 根因：`WorkspaceBoard.vue` 查看态工具栏对返回按钮**无条件渲染**（`v-if="!editing"` 只控制整个工具栏）。Q08（645:28703）设计语义是"保存后的查看态"回跳进入来源，直达首页不属于该场景。

## 2. 变更摘要

- `src/modules/workflow/components/WorkspaceBoard.vue`：新增 `hasAuthoringBackSource()`——仅当 `history.state.back` 以 `/workspace/config` 或 `/workspace/edit`（保存后查看态的编排来源）开头时渲染返回按钮；`goBackFromView` 简化为 `router.back()`（按钮仅在来源存在时可点）。模板加 `v-if`，Q08 注释补 B021-001 依据。
- `src/modules/workflow/views/WorkspaceHome.spec.ts`：router mock 补 `back`；beforeEach 清理真实浏览器历史态；原 Q08 条件断言改为确定性两用例（有编排来源→渲染且 `router.back()`；无来源→不渲染、标题与配置入口保留）。

## 3. 验证与结果

- 聚焦单测：`npx vitest run src/modules/workflow/views/WorkspaceHome.spec.ts` → 10/10 通过。
- 门禁：`pnpm typecheck` 退出码 0；`pnpm lint` 退出码 0。
- 实机浏览器验证（127.0.0.1:5173，admin 登录，ZCode 内置浏览器，viewport 1280×720）：
  1. 登录落地 `/workspace`：`.wsd-viewbar__back` 数量 **0**，标题「我的工作台」与「配置工作台」入口保留；整页截图留存，左上角无返回按钮（对照 Owner 原截图红框位置）。
  2. 进入 `/workspace/config` → 点「返回」回 `/workspace`：返回按钮出现（数量 **1**，back 记录编排来源）→ 点击后回到 `/workspace/config`，Q08 保存后查看态回跳语义保持可用。
