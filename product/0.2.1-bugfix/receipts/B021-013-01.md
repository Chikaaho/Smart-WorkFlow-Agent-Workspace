## 1. 定位

- 症状：筛选栏第一项「租户名称」的输入框右缘压住第二项「状态」的标签文字。
- DOM 实测（任意视口可复现）：输入框右缘 x598 vs 「状态」标签左缘 x580，**重叠 18px**（1280 视口）；zoom 0.5 模拟 2560 视口同为 18 CSS px。
- 根因：`TenantList.vue` 残留像素规格时代的筛选宽度覆盖（`ca674de` 引入）——item 盒 `width:310px`、名称控件 `width:220px`、状态控件 `width:100px`；而现行为 design 外观 `StandardListTemplate` 规定 `.list-filter-item__control { flex: 0 0 272px }`。层叠结果：item 盒 310px（租户页规则胜出），控件按 basis 撑 272px（basis 优先于 width），内容需 56+8+272=336px > 310px → 控件溢出 item 盒 26px，压到下一项标签。
- 与 B021-012 操作列改动无关（筛选栏未动过，系历史遗留，本次被 Owner 宽视口截图暴露）。
