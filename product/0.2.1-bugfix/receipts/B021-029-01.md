# B021-029 执行回执（第 1 轮）

日期：2026-11-03。Owner：选择器的部门树默认收起（不要全展开）；未选择部门时不展示人员。

## 1. 定位

- 人员页签组织树带 `default-expand-all`，两层部门全铺开；
- 打开弹窗即 `load('')` 拉全量候选并渲染，未选任何部门也能看到所有人。

## 2. 修改（Web `dbb2074`，3 文件）

- 人员页签树去掉 `default-expand-all`（`default-expanded-keys=[]`），根/总公司默认收起；
  「部门」页签的负责人多选树保持原行为不动。
- `filteredCandidates`：`deptId == null` 直接返回空数组——先选部门再出人（已选栏不受影响，
  仍可移除已选）。
- 空态文案分两种：未选部门显示「请先在左侧选择部门」（新键
  `approverPicker.selectDeptHint` / en），选了部门无匹配仍显示「无匹配候选」。
- 打开弹窗时仅在带 `initialIds`（需要回显已选人员）时静默取一次候选，其余情况不再预拉。

## 3. 验证

- 门禁：typecheck 0 / lint 0 / 1996 通过 3 跳过 / build 4.06s。
- 实机（IAB，新标签页）：打开即树收起（expanded=0，仅 3 个根节点可见）、人员列表 0 行、
  提示「请先在左侧选择部门」；展开 总公司→分公司2 点「部门1」→ 列表出现赵磊/孙悦 2 人；
  （点中「总公司」节点 → 全公司 14 人，符合「部门+子孙」口径。）
