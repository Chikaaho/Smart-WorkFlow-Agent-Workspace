# B021-019 执行回执（第 1 轮）

日期：2026-11-03。Owner 截图：组件库「单行文本」「多行文本」并列，而属性面板「输入方式」
本就能单行/多行互切——指示合并为一个「文本输入」组件。

## 1. 定位

- 组件库（`FieldPalette.vue`）在 TEXT 主入口之外另立 `{ type: 'TEXT', variant: 'multiline' }`
  变体入口，拖出即 `multiline=true`；与 `TextConfig.vue` 的「输入方式」下拉（同一字段
  `multiline` 开关）功能重复，一个属性被做成两个组件。
- 配套：`FieldListPanel`/`FieldConfigPanel`/`PublishedSnapshotViewer` 的控件名按 `multiline`
  分别显示「多行文本」/「单行文本」，把输入方式当成了控件类型。

## 2. 修改（Web `ed508ab`，9 文件，已推送）

- `FieldPalette.vue`：删除 multiline 变体入口与分支；变体类型收窄为 DICT 下拉/单选。
- 注册表 TEXT 名称 `form.fieldTypeText`：「单行文本」→「文本输入」（库内名 = 拖出默认字段名 =
  属性面板控件名 = 字段清单/发布快照控件类型，单一名称源不变）。
- `TextConfig.vue`「输入方式」选项改「单行 / 多行」（新键 `fieldInputModeSingle` /
  `fieldInputModeMultiline`）；`FieldListPanel`/`FieldConfigPanel`/`PublishedSnapshotViewer`
  控件名不再按 multiline 分叉。
- 语言包：删 `paletteMultiline`、死键 `paletteSingleLine`（zh/en）。
- 存量数据：`TextField.multiline` 契约与运行态渲染（textarea）不动，已有多行字段不受影响。

## 3. 验证

- 门禁：typecheck 0 / lint 0 / 1992 通过 3 跳过 / build 4.09s（FieldPalette.spec 改为断言
  单一入口+无「多行文本」；FieldListPanel.spec 改为单/多行同显「文本输入」）。
- 实机（IAB，新标签页）：组件库基础组首项「文本输入」，无「多行文本」；拖出后画布标签
  「文本输入」、属性面板控件名「文本输入」、输入方式默认「单行」（INPUT）；切「多行」后
  画布改渲染 TEXTAREA rows=3。
- 排障记录：旧标签页因设计器未保存草稿触发 `beforeunload`，reload/goto 全部被静默拦截，
  页面 33 分钟未刷新造成「语言包陈旧」假象；换新标签页即正常。期间重启了 Vite dev server
  （PID 3120 → 9600），服务正常。
