# B021-028 执行回执（第 1 轮）

日期：2026-11-03。Owner 截图：选择审批人弹窗在较矮窗口下整块溢出看板，下半部分跑出弹窗边界。

## 1. 定位

- `.el-dialog.approver-dialog` 固定 `height:732px; margin-top:146px`——视口高度 < 878px 时
  必然越界；三栏 `.approver-dialog__panes` 固定 `height/min-height:450px`，且弹窗
  `.el-dialog__body` 不是 flex 容器、无 overflow，组织树节点多时直接把内容顶出弹窗底缘
  （截图中的下半部分崩坏即此）。
- el-overlay 本身并不滚动，弹窗也不允许内部滚动：高内容无处可去，只能溢出。

## 2. 修改（Web `471e8b7`，2 文件）

- 弹窗：`height: min(732px, calc(100vh - 32px))`；去掉自算 margin-top，改 `margin:0 auto`
  交还 EP overlay 的 flex 居中；根节点改 flex column（header/body/footer 三段）。
- `el-dialog__body`：`flex:1; min-height:0; overflow:hidden; display:flex column`。
- 三栏 `.approver-dialog__panes`：去掉固定 450，改 `flex:1; min-height:0`；每栏
  `.approver-pane` flex column + `overflow:hidden`。
- 组织树 `overflow-y:auto`、候选人列表 `.approver-pane__rows` `overflow-y:auto;
  overflow-x:hidden`、单栏（部门/角色/规则）`overflow-y:auto`——各栏独立滚动。
- 弹窗宽度不变（980），仍居中。

## 3. 验证

- 门禁：typecheck 0 / lint 0 / 1996 通过 3 跳过 / build 4.37s。
- 实机（IAB 1280×720）：弹窗 top 0 / bottom 688，`inside=true`（不越界）；组织树出现内部
  滚动条；候选人区无横向滚动条；底栏 取消/确认选择 固定在弹窗内侧。
- 视口高度换算：height=min(732, vh-32)，600 高窗口 → 568，内容在栏内滚动。

## 4. 待验收

- 任意窗口高度打开选择审批人：弹窗整体不超出视口，三栏各自上下滚动，底部按钮始终可见。
