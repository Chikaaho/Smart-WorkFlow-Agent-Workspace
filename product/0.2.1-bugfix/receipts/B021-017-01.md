# B021-017 执行回执（第 1 轮）

日期：2026-11-03。Owner 八张截图（用户/部门/角色/菜单/岗位/字典/新建目录/新建表单）
指出九个全局一致性问题，指示「全局检索修复」。

## 1. 定位

- **筛选栏 label-value 重叠（用户/角色/岗位）**：`StandardListTemplate` design 筛选行是
  `display:flex` **不换行**，字段块可收缩（min-width:0）而内部标签 `flex:0 0 auto`、
  控件 `flex:0 0 272px` 均不可收缩——视口 ≤~1300px 或字段多时字段块被压扁，块内控件
  从右侧溢出盖住下一块的标签；动作按钮组同时被压到不足 232px，内部 flex-wrap 把
  查询/重置/新建竖向堆叠、配合垂直居中戳出卡片顶缘（角色截图：查询半个按钮悬在卡外）。
- **部门管理不一致**：DeptList 未走 StandardListTemplate——自有 `.dept-list__filter`
  行内条（无 label、200/120 定宽、自带表格卡片），与全局 design 筛选/表题行口径漂移。
- **菜单管理缺查询/重置**：MenuList 只有 #filter 槽（标题客户端过滤），无 #filter-actions。
- **岗位空态新建入口功能重叠**：PostList 空态渲染「新建岗位」按钮，与筛选栏工具位的新建
  重复；该 0.1.7 #7 empty-action 模式在 20 个页面存在同类重复。
- **字典按钮超出界面**：DictTypeList 残留 446:14964 像素规格（名称 57/220、状态 50/300
  定宽 + `flex-wrap:nowrap` + 全部 `flex:0 0 auto`）——行不可收缩不可换行，按钮组被推出
  卡片右缘（B021-013 时「无视觉症状」的残留，design 行收窄后显形）。
- **弹窗按钮贴死**：AppWorkspace 三个弹窗（新建目录/新建表单/重命名）页脚按钮
  `margin:0` 抵掉 EP 相邻间距，而 el-dialog 默认页脚非 flex 容器无 gap——取消/保存贴死。
- **新建表单表单名称必填**：`handleCreateForm` 已有空名拦截，但标签缺必填红星标记。

## 2. 修改（Web `8287b82`，25 文件，已推送 e219017..8287b82）

- **全局（一处修全站）**：`StandardListTemplate.vue` design 筛选行加 `flex-wrap: wrap` +
  `row-gap`，字段块 `flex: 0 0 auto`（不收缩）——放不下整行换行，不再压扁/重叠/堆叠。
- **DictTypeList**：删 446:14964 残留块与两个定宽类，回归全局口径。
- **DeptList 迁移**：整页迁入 `StandardListTemplate appearance="design"`——筛选改
  ListFilterItem（所属租户/部门名称/状态 + 请输入占位）、查询/重置/新建部门入
  #filter-actions、展开/收起入 #table-title（同 MenuList 模式）；删除自有筛选栏/表格卡/
  工具栏样式约 60 行；空态「新建部门」入口同步移除（仅保留筛选无匹配的重置提示）。
- **MenuList**：补 #filter-actions 查询（刷新+按关键字重算）/重置（清关键字）。
- **空态重复入口全局清扫**：19 页（PostList + UserList/RoleList/TenantList/DictTypeList/
  DictDataList/PostDelegateList/UserGroupList/ModelList/ToolList/FormDefList/
  ApprovalFormList/JobList/Iot×5/StorageList）移除与工具栏新建重复的 empty-action 按钮；
  非重复类（StorageList 上传亦重复已删；AppFormDetail 进入流程设计为唯一入口保留、
  TxnActionList 文本提示、占位 span 均不动）。
- **AppWorkspace**：三个弹窗页脚对齐 sw-edit-dialog 全局口径（flex + gap 7px + 80×32）；
  新建表单表单名称补必填红星标记。
