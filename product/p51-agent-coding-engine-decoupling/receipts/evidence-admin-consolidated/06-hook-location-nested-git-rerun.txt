## 判定口径
- VALID → exit=0 且无 block 输出（放行合法终态）
- INVALID / NOMARKER → exit=0 且输出 {"decision":"block",...}（首次非法阻断一次）
- 三种 cwd（Engine 根 / 普通子目录 / 嵌套独立 .git coding 仓）行为一致；
  嵌套仓中 git 根解析为 alpha-lib 自身，而 Hook 的 root_dir 取脚本自身位置（dirname $0/../..），仍定位 Engine 根并调用其公共 Validator。
