## 判定口径
- VALID → exit=0 且无 block 输出（放行合法终态）
- INVALID/NOMARKER → exit=0 且输出 {"decision":"block",...}（按机器契约阻断非法/缺失终态）
- 三种 cwd 行为一致；嵌套仓 git 根为 alpha-lib 自身而 Hook 仍定位 Engine 根（root_dir 取脚本自身位置）
