# 项目说明（治理夹具：Beta）

## 1. 项目身份
- 名称：治理夹具 Beta（无业务语义）
- 目标：验证异构多仓项目的仓库动作、资源约束和验证基线互不串用
- 非目标：不含任何业务实现

## 2. 仓储关系
- 结构：多仓（异构）
- coding 仓库：
  - `alpha-lib/` — 文档库；唯一动作「文档验证」，资源上限 256M，基线 ALPHA_BASELINE=doc-1
  - `beta-tool/` — 静态检查仓；唯一动作「静态检查」，资源上限 128M，基线 BETA_BASELINE=static-1

## 3. 工程动作与验证入口
- alpha-lib 验证入口：`cat alpha-lib/VERIFY.md`
- beta-tool 验证入口：`grep -q BETA_STATIC_CHECK_MARKER_OK beta-tool/STATIC_CHECK.txt`
- 未声明动作：编译、数据库迁移、服务启动、制品构建、部署 —— 两仓均不存在

## 4. 资源与并发
- 各仓动作的资源上限以各仓工程宪法为准（alpha 256M / beta 128M，互不串用）
- 跨仓并发：两仓动作可独立执行，互不依赖
