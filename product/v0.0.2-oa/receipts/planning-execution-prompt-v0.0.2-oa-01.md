## 3. 锁定项与禁止重验

禁止无依据重验：A2分类/目录/绑定发起链；催办5路并发、冷却、非发起人和结束分支；两用户布局保存及reset；显隐代表链；单发失败、低权限通知拒绝、审批状态不变；user/page与by-key当前不复现结论。指针统一见规划验收02 §2。若R1/R5/R7修复触及其依赖路径，只复验受影响断言并写明失效依据。

## 4. 执行顺序与证据封装

1. 建立R1—R9账本，固定最终候选及对象；先修R1、R5、R7，可并行准备R2—R4场景。
2. 在最后实现快照完成R1—R7行为采集；每项原始流独立保存，响应记录方法、路径、HTTP status和必要脱敏体。
3. 最后统一执行R8工程门禁；用工具生成报告计数、清单与SHA256清单并回读校验，清单排除自身。
4. 生成R9脱敏生效索引，再按“原子ID → 原件路径:行号 → 实际结果 → 边界”写回执03。

允许实际API/浏览器、隔离测试、报告统计、指纹与受控进程收尾。数据库删除、秘密读取、远程、main、标签和发布不在本提示授权内。不得复写历史失败附件、用近似用户/实例替换而不登记、把业务code当HTTP status、把单测冒称浏览器、或在存在可执行缺口时提交等待验收。
