## 4. 规划裁决

### 4.1 完整移除第三方图形依赖

维持正式方向：生产依赖、包清单、锁文件、源码、adapter、页面、样式、测试、静态产物和运行 DOM 均需零残留。页面级隐藏或只删除 Viewer import 不构成完成。历史回执文本不属于生产残留，不改写。

### 4.2 多实例并发与调度

G8 要求至少两个独立应用进程/实例连接同一数据库，对同一会签结算边界发起真实竞争，并证明只有一票/一次结算/一个流程结果。单 JVM 多线程可作为前置集成证据，但不能替代该结果。

G12 仍属 I3：需用真实调度入口证明到期触发、服务重启恢复、重复扫描/竞争认领、通知失败及最终单次动作。是否使用 Quartz 不是验收要求；执行层可沿用当前 `@Scheduled + DB`，但必须证明行为成立，不得把验证移入 I4。

### 4.3 意见表单不可变引用

允许“不冗余整份 definition”，但“等价不可变引用”必须满足：引用目标在历史生命周期内不可被原地改写或删除；能够按动作发生时版本稳定解析；后续发布、停用或编辑后，历史意见仍逐字段按原定义解释。执行层必须提交引用身份、定义版本/快照回读和版本变化前后行为。若现有引用不能满足，则需补真实快照或等强度不可变存储。

组件适用矩阵是 I3 必交付物，不自动沿用 I2。每个 I2 组件必须明确“可用于意见表单 / 不可用于及原因”，可用组件提供服务端校验与历史回显行为；不可用组件在设计端和构造请求中均被拒绝。
