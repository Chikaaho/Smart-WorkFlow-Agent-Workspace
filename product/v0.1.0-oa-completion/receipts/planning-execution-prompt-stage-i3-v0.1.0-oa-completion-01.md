## 4. 对象、生命周期与秘密约束

- 首先冻结一个最终候选：源码状态指纹、JAR hash、Web 产物 hash、数据库 ID、两个进程 PID/端口。所有新行为附件必须引用它。
- 已销毁对象允许换新，但须登记旧 ID → 新 ID；禁止用接口脚本预置结果替代浏览器操作、用 superadmin 替代业务角色、用单线程替代双进程。
- 场景开始前建立采集点，完成全部回读后再清理；最终清理必须再次回读，不以执行 kill 命令本身代替零残留。
- 不在 product、回执或 manifest 中保存 JWT、Bearer token、密码、私钥正文等可重放凭证。日志只保留身份标签、响应码和不可逆摘要。
