## 2. 问题事实

| 项 | 内容 |
|---|---|
| 观察结果 | 登录后的工作台在不同分辨率下仍按固定内容宽度和固定面板几何布局呈现，宽屏有未利用空间；左下角显示工作空间提醒。 |
| 期望结果 | 工作台内容随视口宽度和高度自适应，使用可用空间且在窄屏保持可读；移除左下角工作空间提醒。 |
| 影响入口/身份/对象 | 登录后的工作台 `/workspace`；所有登录身份。 |
| 复现条件 | 登录后以不同宽高打开 `/workspace`，并观察左下角工作空间区域。 |
| 风险等级 | 中（登录后主工作入口的可用性和视觉布局受损）。 |
| 受影响仓库 | Web |
| 当前结论 | 已收件，待 BUG-002 的卡片配置契约稳定后单独定位与修复样式及提醒入口。 |
