## 本轮发现的两个真实缺陷（已修复并回归）

1. **放弃分支不还原表单标题**：`items` 回滚到基线但 `title` ref 未还原，且基线被改写为已编辑内容——放弃后编辑内容仍留在页面。修复：从基线 JSON 同时还原 `title`。
2. **路由离开守卫对同组件参数跳转不触发 / 双触发**：`/form/designer/A → B` 为同一路由记录的参数更新，`onBeforeRouteLeave` 不触发（守卫失效）；同时挂 leave+update 两钩子则一次导航连续弹两次。修复：两钩子均注册并以 `to|from` fullPath 为键共享同一次询问（Promise 去重，用后即清）。

原始记录：`requests.json`（各分支 DOM/状态 JSON）、`before-after.json`（关键步骤持久化对照）。
