# R2 结论

| 入口 | 取消 | 放弃 | 保存并继续 | 保存失败 |
|---|---|---|---|---|
| 发布（C1） | 锁定项（首轮真实执行） | ✓ 放弃还原标题并继续发布确认框 | 锁定项（首轮） | ✓ 发布确认框未出现，发布被阻止 |
| 切关联流程（C2） | ✓ 停留 design、编辑保留 | ✓ 切换成功、内容还原、零持久化 | ✓ 切换成功、持久化成功 | ✓ 未切换（停留 design）、零持久化 |
| 路由离开（C2→B） | ✓ 留在 C2、编辑保留 | ✓ 落到 B、内容还原、零持久化 | ✓ 落到 B、持久化成功 | ✓ 未离开、零持久化 |

- 每一分支均记录 URL / tab / 组件状态 / 持久化前后值（`requests.json`、`before-after.json`）。
- 反向零残留断言：所有放弃/失败分支的编辑内容在持久化层零残留（curl 逐项回查）。
- 本轮为满足该证据修复的两个真实缺陷（放弃不还原标题；路由参数跳转守卫失效/双弹窗）已随修复回归。
- **结论：R2 通过。**
