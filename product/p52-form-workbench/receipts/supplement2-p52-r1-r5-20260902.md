## 2. R1—R5 关键结果（详见各证据包）

- **R1**：真实浏览器 + 真实后端，经传输层中间人对表单 A 的身份/definition 两请求人为延迟 10s；页面在 A 在途期间（B 请求 33ms 完成）已成功进入 B。A 迟到返回后，B 的 URL、身份区（`p52_r_form_b_… | 已发布 | V2`）、标题、formId/status/activeTab/拒绝态逐项不变（`before-after.json`）。页面 performance 网络记录给出时间顺序（A start=718ms/dur=10006ms；B start=2768ms/dur=33ms）。
- **R2**：发布、切关联流程、路由离开三入口 × 取消/放弃/保存/保存失败全分支真实页面执行（发布入口的取消与保存并继续为锁定项未重跑）：取消一律留在原页且保留编辑；放弃一律继续目标动作、内容还原、持久化零残留（curl 逐项回查）；保存并继续一律继续目标动作并持久化成功（curl 回查含编辑）；保存失败一律阻止目标动作（发布确认框未出现 / 工作区未切换 / 路由未离开）且编辑与未保存标记保留。
- **R5**：低权限 token 对真实 DRAFT 流程 P 直调 **保存草稿图 → 403、发布 → 403、删除 → 403**；越权尝试前后流程 name/version/status/elements 逐字段一致（零副作用），记录数不变；admin 对照保存草稿图 HTTP 200 落库成功、发布请求 HTTP 200 通过权限网关（业务图校验 2000 属另一层）。
- **R3 冲突**：现有发布模型为一次性状态迁移（DRAFT→PUBLISHED 单向，二次 publish 实测 1100 拒绝；已发布表单全页冻结，草稿必然无快照）——「有历史快照且可编辑当前态」互斥不可构造，等价能力属方向 §4 排除的版本治理范畴。**需规划裁决场景改写或前置能力立项。**
- **R4 冲突**：鉴权唯一入口 `PermissionService` 为权限码集合（功能级）判定，无表单实例 ACL/所有者模型；「某真实表单对低权主体不可见、对 admin 可见」无法在数据层表达。最小必要决策（资源可见性模型、form 读取链对象级鉴权策略、工作台/列表一致性口径）属产品/架构裁决。**如实 BLOCKED。**
