1. 批准 P53 在 Web 工程内引入 `@playwright/test` 作为视觉回归开发依赖；后台/headless 结果只能作为组件或隔离回归证据，正式浏览器验收仍必须来自用户可见、可交互会话。

4. 设计稿不自动授权新增认证、租户、多工作空间、流程节点、动态规则、审批快照、公告/知识或修改密码等 Server 能力。缺少真实能力的入口不得以假按钮、静态成功或演示数据实现。
