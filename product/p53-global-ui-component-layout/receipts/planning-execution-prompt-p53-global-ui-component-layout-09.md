## 3. 失败分类与处理边界

34项账本每项只能归入下列一类，并附实际证据：

1. **过期定位/断言**：生产行为已由锁定证据证明正确，测试仍引用旧DOM；改为当前稳定语义定位。
2. **合法快照漂移**：当前画面与review-07/08锁定设计或正式证据一致；人工核对差异图后更新该精确快照，记录原因与哈希。
3. **状态fixture漂移**：测试数据/状态不再能进入目标状态；修复fixture但不得改成平行页面或假生产能力。
4. **真实产品缺陷**：当前画面违反方向；仅修该缺陷，并按影响重跑命中的设计节点/正式路径。
5. **测试已不适用**：必须给出方向条款及等价覆盖映射后替换；不得简单删除或skip。

允许把相同根因跨三个桌面视口合并为一个修复组，但最终账本仍须列出全部34个失败实例与处理结果。
