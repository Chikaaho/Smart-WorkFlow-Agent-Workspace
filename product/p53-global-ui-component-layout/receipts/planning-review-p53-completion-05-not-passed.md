## 3. 证据原则

1. **Figma MCP 优先**：先真实尝试可用的只读 Figma MCP。可用时不得跳过并只看导出图；不可用、无权限或对象不可读时，保存工具名、参数边界、错误类别与结果，再退回本地锁定 PNG/SVG。MCP 不可用不构成阻塞，因为本地设计包是已授权兜底。
2. **外部设计源对比**：禁止用当前实现更新出的 Playwright 基线证明设计还原度。自有基线只证明回归稳定；还原结论必须来自 Figma 节点或锁定设计图片与最终运行界面的成对比对。
3. **颜色优先且可量化**：至少给出设计色、令牌值、浏览器 computed style、最终截图内部稳定区域采样值和差异结论。抗锯齿边缘不得作为主采样点；因 WCAG 做的必要偏差须逐项登记理由和对比度。
4. **整体 UI 不能只验颜色**：字体层级、字重、行高、宽高、间距、对齐、圆角、描边、阴影、图标、层级、响应式与浮层位置均属于还原度；不得以功能可用或全量视觉 0 failure 替代。
5. **动态内容可受控屏蔽，结构不得屏蔽**：仅允许屏蔽真实动态文本、时间、ID、头像等不可稳定内容；遮罩区域、理由和面积必须登记。导航、容器、按钮、表单、卡片、弹窗及颜色不得被遮罩。
