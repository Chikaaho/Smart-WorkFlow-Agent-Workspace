## 4. 偏差裁决

1. 不给公共响应增加 category 字段：条件接受。主方向要求九类语义和可区分行为，并未强制线上字段。最终必须证明业务错误、HTTP 错误和传输错误均得到正确且单一来源的恢复行为；若做不到，再由执行层提出兼容扩展，不提前复制第二套分类表。
2. BPM 草稿语义保留数值 400、以 errorKey 消歧：符合旧数值 code 兼容裁决。
3. job_log.exception_stack 不做迁移：条件接受。最终页面、接口和说明必须把该内容呈现为事件引用/分类，而非“异常栈”；既有消费者不得误读，完整诊断仍需受保护可定位。
4. Agent 保留平台自身的设计错误原文：条件接受。仅限设计者确需的产品级诊断，必须通过受控标记证明不包含第三方原文、路径、栈、租户或秘密。
5. SsoRejectionException 改变失败侧异常类型：可接受。最终以认证兼容、防枚举、状态码/errorKey 和真实接口行为为准。
