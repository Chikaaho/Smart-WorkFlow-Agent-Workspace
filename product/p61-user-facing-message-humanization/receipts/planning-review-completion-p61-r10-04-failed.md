## 2. 规划口径纠正

二级提示 R2c-I 要求“同一导入批次至少一项成功、一项失败”，与既有、明确且合理的整批原子回滚契约冲突。该要求属于规划口径错误，现撤回，不计为执行失败，也不要求把导入改成部分提交。

纠正后的验收口径：

- 保持整批原子契约；混合输入允许 `success=0`。
- 主结果四项必须满足 `total = success + failure + processing`。
- 三行均未落库时，用户可见主计数应为 `total=3 / success=0 / failure=3 / processing=0`；可在下钻中再区分“输入错误 1 / 连带回滚 2”。
- 为兼容旧调用方，可保留原 `errorCount=1` 表示逐行输入错误数，但新增或展示的总体失败数必须包含连带回滚行，不能用说明文字代替主计数。

另外两项不构成 P61 阻塞：真实 Provider 成功链已由 Owner 明确延期，不是“待规划确认”；TEXT 字段声明 `length` 未校验是 P61 范围外的表单校验候选，另行进入需求池评估，不并入本轮实现。
