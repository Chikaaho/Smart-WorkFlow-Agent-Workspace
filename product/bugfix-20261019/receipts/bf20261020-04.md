## 1. 缺陷与修复

| 项 | 现象 | 修复 |
|---|---|---|
| 详情打开方式 | 表单数据详情、我发起的实例详情跳转整页 `form-render`，与抄送详情的弹窗体验不一致 | 新增共享 `BusinessDetailDialog`（`src/components/business-detail/`）；抄送详情、我发起的实例详情、表单数据列表「查看」统一改为只读弹窗，不再跳整页 |
| 详情内容 | 弹窗顶部展示流程名称、实例状态、表单名称、抄送节点、业务单号、抄送时间、投递状态等非业务元信息 | 整块移除；弹窗只保留「表单数据」卡与「流程详情」卡（流转记录/流程图/审批详情） |
| 选择项回显 | 设计器的多选/下拉（如「演练类型」）在详情中渲染成禁用输入框 | `MULTISELECT` / `DICT`（下拉形态）只读时按设计器同一套选择项展示：全部选项 + 选中项打勾；不再渲染 `el-select` 输入框 |
| 画布实时改名 | 节点名称输入后画布不更新 | `updateNodeConfig` 同步 `label`；名称输入以事件值立即写模型并推进快照 serial，逐字联动画布 |
| 技术标识/备注 | 属性面板展示 formKey、字段 key、脚本摘要等 | 审批意见表单只显示业务名称；字段/节点/流程/表单选择器去掉 key 后缀；脚本摘要改为「已配置」；移除技术说明备注 |

## 2. 关键实现

- `src/components/business-detail/BusinessDetailDialog.vue`：统一只读弹窗；按 `formKey + recordId` 加载表单记录与实例关系，或直接消费调用方传入的 `record / approvalHistory`；无元信息。
- `src/components/business-detail/BusinessFormReadonly.vue`：从 workflow 模块移动到共享组件，任务详情与各详情弹窗共用。
- `MyCc.vue`：改用共享弹窗，传入抄送快照与审批历史。
- `MyInstances.vue`：`openDetail` 不再 `router.push` 到整页，改为统一弹窗；移除原技术表格与 P64 诊断表。
- `FormData.vue` / `AppFormData.vue`：行「查看」改为统一弹窗，编辑仍走原页面。
- `MultiSelectControl.vue` / `DictControl.vue`：只读回看改为静态选择项列表（选中打勾），并保留未选择兜底。
- `ProcessDesigner.vue` / `process-graph`：节点名称逐字同步画布；属性面板去技术标识与脚本摘要。
- `InstanceFlowPanel.vue`：意见详情字段按表单定义显示业务标签，不再显示内部字段名与表单 ID。
