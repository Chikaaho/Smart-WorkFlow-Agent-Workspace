# ADR-P62-002：分级执行与统一命令

日期：2026-09-30；Planner；状态：拟议，待限定探索定案；不构成业务实现授权。

事实依据：探索附件B/C（事务首阶段前快照）、已通过LT03事务范围补证、审查03与首阶段最终裁决。LT03明确事务动作仅有HTTP生产调用方，尚无命令消费者/BPM节点调用；不得把规划接入当作既有事实。

| 决策主题 | 规划选择 | 定案所需事实与影响 |
|---|---|---|
| 分级模型 | 形态、优先级、等待、完成点、事务边界独立；等级不代表更弱一致性 | 现有配置/发布/查询兼容字段；旧P0/NORMAL映射 |
| 命令统一 | 统一逻辑身份和状态语义，复用既有命令及动作幂等；不预设所有物理记录必须合表 | 动作与BPM身份映射、唯一键及同键异载荷处理、查询权限接缝 |
| 生产轻流程 | 有限自动步骤调用受控动作，沿用现有规则与权限；先评估既有图/节点扩展 | 现有节点注册、失败恢复及事务边界能否满足；不能复用时列出最小差异再裁决 |
| 可靠恢复 | 持久队列/意图优先；本阶段不做五套调度整体收敛 | 新增业务副作用与领取租约的防旧执行者边界，提交中断如何恢复 |
| 未知结果 | 本地超时与外部待核实分开；结果不可证明时保留不确定性 | 现有适配器可查能力、人工核实入口及审计边界；不承诺物理恰好一次 |
| 兼容与回退 | 追加演进、旧对象语义不变、新入口可停用 | 旧客户端枚举处理、在途行、混版本可否运行及回退数据界限 |
