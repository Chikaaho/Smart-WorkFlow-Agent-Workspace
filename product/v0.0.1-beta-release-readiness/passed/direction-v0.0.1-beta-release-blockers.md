关闭当前阻止 `v0.0.1-beta` 发布的三个最小缺口，使项目能够从干净环境复现前端全绿测试，并让首次启动说明准确、完整地覆盖后端密钥与 Redis 运行前置条件。

## 二、已锁定通过项

以下证据已在发布核验中通过，本轮不得无故重做或扩大修改：

- 真实页面核心业务闭环：用户/组织/角色、表单、单节点流程、提交发起、待办审批、结果与流转记录回看；
- 后端根全量测试 `955/0/0/0`；

若本轮实际修改直接影响某一已锁定项，只允许对受影响范围做必要回归，并在回执中说明影响关系；不得重新展开完整业务验收。

## 三、唯一修复范围

### B1：前端全量测试必须可在干净环境复现

- 当前唯一失败 `tool-production-menu-chain-live.spec.ts` 不得依赖人工预先创建的 `tooluser/user123` 或其他工作区外状态。
- 该测试及其所需账号、权限、菜单和后端前置必须由版本化、可重复的测试环境或测试准备机制完整建立；从全新 H2 数据库和当前 checkout 启动后即可独立运行。
- 不得通过跳过、删除、弱化断言、改成固定 Mock 成功、沿用污染数据库或仅修改正式基线数字来消除失败。
- 修复后前端全量测试必须零失败、零意外跳过，计数与实际输出可复算。

### B2：`SW_CIPHER_KEY` 首次启动前置必须完整可执行

- README 的最小启动路径必须明确 `SW_CIPHER_KEY` 是后端启动必需配置，并说明用途、格式/长度要求、安全生成方式和注入方式。
- 文档不得提供可复制到生产的固定密钥，不得把真实密钥写入仓库、示例输出、测试日志或提交记录。
- 用户从干净 shell 按 README 准备该变量后，后端 dev profile 应能完成启动、迁移和健康检查；缺失或非法时应明确失败，不能表现为含糊的依赖链异常而无配置指引。
- 根 README、后端 README、环境变量示例或其他直接启动入口之间不得出现相互冲突的必需项口径。

### B3：Redis 作为 beta 必需运行依赖准确呈现

- `v0.0.1-beta` 的 dev 主链将 Redis 视为必需运行依赖。所有面向首次启动的 README/环境说明必须明确这一点，不再把无 Redis 的登录后主链描述为可用。
- 启动说明应提供 Redis 的最小准备、连接配置和可验证的就绪条件，使用户能够在启动后端前确认 Redis 可用。
- 按文档启动 Redis、后端和前端后，登录及至少一个受保护请求必须成功；Redis 不可用时，故障提示和排障入口应能让用户识别依赖未就绪，不能误导为账号或权限问题。
- 根 README、后端 README及相关环境说明对 Redis 必需性、默认地址和覆盖方式必须一致。

## 六、主要风险

- 仅把 `tooluser` 加进本地数据库会继续制造不可复现基线；测试前置必须随 checkout 可建立。
- 固定或弱密钥示例可能被误用到生产；文档必须教用户生成和注入，而不是提供共享密钥。
- 只修改一份 README 会留下入口口径冲突；所有直接启动入口必须一致。
- Redis 启动成功不等于会话链可用；必须用真实登录后的受保护请求证明依赖闭环。
- 当前根仓、后端和前端是独立 Git 仓库；修复完成后的候选仍需分别冻结 commit，不能用单仓状态代表整体发布物。

## 七、验收标准

执行层提交完整行为回执后，规划只按以下标准复核：

1. 全新 H2 数据和当前 checkout 下，前端全量测试零失败、零意外跳过；B1 原失败用例不依赖人工账号或历史数据库。
2. B1 前置来源可追溯到版本化文件或可重复环境准备，删除本地历史状态后仍可复现。
3. 从干净 shell 按 README 准备 `SW_CIPHER_KEY`，后端 dev profile 完成启动、V44 迁移和健康检查；文档不包含固定真实密钥。
4. README 与相关启动入口明确 Redis 为 beta dev 主链必需依赖，连接方式、默认值、覆盖方式和就绪检查一致。
5. 按文档准备 Redis 后，真实登录成功且受保护请求返回正常业务结果；Redis 不可用时能够从错误或排障说明准确识别依赖问题。
6. 根 README、后端 README、前端 README中与本轮相关的启动口径无矛盾，所有新增相对链接可达。
7. 受影响质量门具有实际命令、退出码、可复算计数和原始输出；不得用测试名、源代码片段或人工结果表代替行为证据。
8. 修改范围仅覆盖 B1～B3；未创建 tag、未提交、未推送，未改变正式功能状态与计数。
9. 回执明确列出三仓修复后的分支、HEAD、工作区状态和必要改动归属，供后续冻结候选 commit；不得把未提交修改描述成可发布提交。
