## 产品行为

- 展开侧栏的底部提供固定折叠条，显示向左箭头和“收起”；收起后底部对应位置提供向右箭头，点击恢复展开。箭头使用可辨识的折叠/展开图标，不做中部悬浮手柄。底部只保留一个该功能入口。
- 底部条固定在侧栏可视区域底部，不随菜单滚走。菜单长时仅菜单区滚动，底部条占据独立空间，不遮挡最后菜单或正文；不能把整条页面滚动当作入口常驻。
- 折叠后保留菜单图标列、选中态、悬浮完整名称和点击导航能力，分组/子菜单仍可达，不能整栏变成空白。
- 有有效图标时显示原图标；没有图标或图标不可用时，显示当前菜单展示名称的第一个可见字/字符作为占位，不以空白或同一个通用图标掩盖缺失。按当前语言的展示名称取值，不取内部路由、权限码；字符显示完整。
- 收起态图标/首字在统一位置居中，选中与未选中样式清晰；展开态菜单名称、层级和可达操作保留。既有路由、菜单顺序及权限保持，不新增或隐藏业务入口。
- 顶部主导航起点、项宽、间距及垂直对齐在侧栏两态不变；底部控件不进入顶栏布局。适用尺寸沿现有布局和原1920/1366及既有移动业务边界，不扩展移动设计器。
