## 关键发现（编译器层）

**Vue scoped CSS 中 `:global(X) Y` 会丢弃后代 Y**——编译产物只剩 `.app-sidebar--admin`（挂在根上），后代规则全部失效；这是本批前两轮 admin 覆盖"写了不生效"的真正原因。全部改为 `:global(X Y)` 整条形式后生效（服务端 CSS 复核选择器原文证实）。
