# 0.2.0 表单授权集成产品边界

2026-10-26｜Planner｜承接DR06与现有能力探索结论

## 目标与授权

`#调用集成` 在可编辑表单的实际事件/字段脚本中，能按已登记、已授权的稳定标识调用平台受控HTTP能力，并返回有类型的结果或可定位错误。依据是 `decision-records-020.md` DR05/DR06；探索为 `search_fallback/0.2.0-authorized-integration-boundary-20261026.md`。本文件是统一总续办02的产品明细，最小映射和执行端口属于原跨仓范围，无需再次等待产品许可。

## 允许能力与授权交集

- 复用现有受控外部工具作为调用目标，补齐表单可消费的受控能力；具体模块、端口与存储适配由Executor决定，保持既有依赖边界。
- 由具有表单设计/管理权限的配置者显式选择该表单允许调用的稳定能力标识，进入定义保存/发布和版本快照；能配置表单不自动授予读取或管理外部工具的权限，候选目标仍取现有有权范围。旧定义没有授权清单时默认不允许调用。
- 服务端按当前登录主体/租户、绑定表单版本、该主体当前合法表单/记录操作、能力所属租户、启用状态及已有能力授权取交集。表单允许清单不能扩大主体原有能力；不以浏览器提交的白名单、角色名或URL作为授权依据。新增最小调用权限须沿既有角色/权限机制显式授予，缺授权即拒绝。
- 加载/提交前仅开放服务端已明确登记为查询、无外部写副作用的能力；方法名称或客户端声称只读不足以证明无副作用。未分类能力默认不能在这两个阶段执行。写副作用限定提交后或已授权的明确服务端业务入口，以稳定提交/动作标识幂等，重试不重复已成功副作用。
- 未发布编辑稿和模拟预览使用明确的样例/隔离结果；只读历史不得发起带副作用调用。旧版本使用自身授权快照，同时受当前租户停用、能力撤销与权限约束；历史快照不恢复已撤销权力。

## 调用与风险边界

客户端仅传稳定能力标识、合法上下文与结构化输入；服务端解析已登记目标及请求方法，校验身份和资源范围，限制超时、输入/输出体积、并发及取消。沿DR05已有更严格预算和既有目标访问控制，禁止通过参数、重定向或代理形成任意URL/内网旁路。日志记录必要调用关联、状态和失败，不保存秘密或无关敏感响应。

本版证明现有受控HTTP调用，不引入新的外部Provider、凭据管理体系或任意脚本网络访问。现有工具无鉴权注入时，不以真实第三方秘密作为本轮前置；使用已授权本机、无秘密且有界的受控端点证明正向与边界即可，不将其冒称第三方集成送达。

## 完成判定

真实链覆盖：有权登记/选择→保存发布→表单宿主识别允许标识→服务端代理调用→页面取得实际结果。必要拒绝覆盖未登记、未授权、停用、跨租户、越权表单/记录、预览/只读及阶段不允许的副作用；失败不得静默返回undefined或伪装成功。事件取消/超时与提交后重试沿原DR05，权限、版本、幂等和消息等已有同路径结果可组合，只补受影响项。
