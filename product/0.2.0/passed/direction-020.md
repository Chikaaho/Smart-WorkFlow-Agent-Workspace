### T020：租户管理

新建租户含名称、首任管理员账号、初始密码，一次操作完成租户及租户内管理员初始化。管理员身份、租户 0 保护、目标租户选择、启停和过期规则按 DR02/DR03 执行。管理页至少有名称/状态筛选和编号、名称、管理员、状态、创建时间；普通租户行编辑，租户 0 仅查看。

超管用户/部门页面提供所属租户、租户范围筛选、按租户分组的组织关系和明确的编辑对象。其他新稿超管管理页同时接入统一租户上下文；只有现有服务端可跨租户管理的对象才开放相应操作。复用并对齐既有租户菜单、权限和授权，不生成第二个入口。既有租户、组织、账号及记录继续可用。

### F020：表单配置与校验

字段查看/编辑权限、动作权限、管理员默认列表配置和受控外部数据源均纳入可操作管理入口。复用现有持久化及服务端鉴权，区分全表单默认配置与用户显示偏好。设计人员仅能引用已授权的稳定数据源/查询标识，表单定义不存连接秘密、任意 SQL 或任意地址。数据源管理员可管理既有支持类型、启停、授权、预览及安全配置；密钥仅进入服务端受保护配置，不回显原值。

文本最小/最大长度、正则、提示按DR04在设计、发布、PC、提交/更新和导入链生效；移动本次不验，既有规则不回退。主表和已支持的明细字段一致。子表字段设计与清单按新稿弹窗表格呈现，添加/编辑/删除/排序、必填/可编辑/显示及已有合法配置可保存回读。公式服务端重算、关联对象权限、发布冻结、表单删除/停启和历史解释继续沿用已过契约。

### J020：表单事件与统一脚本体验

表单提供独立于字段脚本的「事件」配置区，包含三类事件、有序动作、启停及脚本编辑；位置沿表单设计器动作/高级设置，复用新稿事件列表和共用脚本弹窗。稿中现有流程监听页仍用于流程事件。新增事件保存到表单定义并随发布快照冻结，既有字段加载/变更脚本保持原义。

产品事件及函数边界按 DR05—DR07：先完成字段初始化再触发表单加载事件；提交前脚本在最终校验前运行，失败阻断提交；提交后只对已确认成功的业务提交运行，失败不重发业务提交。配置脚本可读写已授权的主表、明细及控件，读取实际可用的流程/组织上下文，调用受控平台能力。表单与流程共用编辑、目录、搜索、参数/返回说明、示例、清空、模拟运行、取消/应用和独立结果区。

### W020：流程入口与办理

复用现有版本挂起/激活、授权规则和废弃接口，补齐可达且正确鉴权的页面/操作。审批区按新稿保留退回目标、退回、更多、驳回、同意，其他已有合法动作进入「更多」；审批意见表单提供暂存。节点允许操作及退回目标在配置和服务端共同执行。加签位置与多人办理顺序、补签、意见草稿及状态兼容按 DR08/DR09 执行。

已有转办、委托、沟通、撤回、会签、实例干预、轨迹、批量审批、交接、模板和分析继续使用原契约；只验证本次实际影响，不因旧 P4 摘要重新开发或全量重验。
