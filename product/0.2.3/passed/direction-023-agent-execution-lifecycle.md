## 4. 产品决策与验收标准（本轮固定）

| ID | 行为边界与通过条件 |
|---|---|
| A01 受理与身份 | 合法请求在等待模型或工具完成之前返回稳定executionId；受理成功前执行意图已持久记录。相同租户/操作者的同一幂等请求回查同一执行；相同键但输入冲突明确拒绝。容量满明确拒绝，不无界排队。 |
| A02 状态与回查 | 区分排队、运行、取消请求及成功/失败/取消等终态，状态只沿合法路径变化；刷新、离开后返回或网络中断后仍能查同一执行。终态唯一，完成输出与记录一致，错误可理解且不暴露秘密。 |
| A03 流式与重连 | 对现有OPENAI_CHAT、OPENAI_RESPONSES、ANTHROPIC提供真实增量路径，不把完整结果拆字伪装流式。事件关联执行和顺序，页面能显示节点进度与模型输出；重连可恢复已收到内容之后的进度，或者明确补取持久快照再接续，不能静默漏片/重复拼接。断线不取消、不重启执行。 |
| A04 取消与竞争 | 排队取消不开始执行；运行取消被受理后禁止调度后续节点/新的工具调用。模型/工具中的请求尽力中断，但未确认结束时展示取消处理中，不谎报已停止。执行成功与取消竞争只产生一个合法终态；完成后取消不会改写结果。重复取消幂等。已发生外部副作用保留记录，不伪称回滚。 |
| A05 超时与恢复 | 超时和异常终止有持久结果，有限排队/并发与资源释放。服务重启后排队意图可受控恢复；在途执行按可证明恢复点处理，无法确认外部效果的标记中断/待核实，不能盲目自动重放。界面可解释，不让记录永久RUNNING。 |
| A06 权限与安全 | 执行提交沿既有权限；普通用户只查询、订阅、取消自己发起的执行，有管理权限者可管理本租户执行；跨租户拒绝。直接API/事件订阅也受相同约束，不只隐藏按钮。异步身份传递不丢租户，密钥不进事件、日志或错误。 |
| A07 兼容与调试 | 新执行绑定发布快照；历史记录可读。保留现有同步接口契约，复用执行核心但不强迫旧调用方切换；新Web执行入口使用异步路径。共享解释器的取消/超时不让调试stop后继续产生新动作，不出现重复step副作用。429轮换、冷却、RAG和工具调用保持。流式已输出后不得无提示换Key重放已显示内容或工具副作用。 |
| A08 可用界面与交付 | 现有执行入口可提交、显示状态/增量、取消、查看最终结果及恢复错误；刷新和重进可用。沿现有UI/文案规范，不新增本轮未约定的像素评分。受影响请求层、代理流式配置、依赖边界与迁移兼容同步验证；正式版本0.2.3与发布实际产物/部署一致。 |

保留的graph快照只冻结既有定义范围，不在本轮承诺完全冻结外部模型/工具/知识库。持久恢复不等于自动重放未知副作用。不得为通过取消标准杀用户既有服务或无界等待外部调用。
