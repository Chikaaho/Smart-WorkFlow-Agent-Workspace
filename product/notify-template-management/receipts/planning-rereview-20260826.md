## 2. 唯一剩余差异

### R1 — 普通用户直接路由仍被放行

- 要求：普通通知用户没有模板查看权限时，既不获得模板菜单，也不能通过直接输入 `/notify/template` 渲染模板管理页；获授 `notify:template:view` 的非超级管理员能够经菜单与直接路由进入。
- 当前事实：菜单权限可以区分，但静态路由守卫不消费权限；普通用户只要有 token 就被放行。
- 判定：**未通过**。后端 API 403 是服务端权限的必要证据，但不能代替方向要求的前端菜单/路由一致性。

### R2 — 当前最终前端树质量门

- 要求：在补证新增生产 handler 以及 R1 必要修正后，当前最终树必须重新形成可复现的前端质量门结果。
- 当前事实：已有 typecheck、lint 和受影响目录测试；没有补证后最终树的 build，且 R1 修正会触碰全局导航行为。
- 判定：**待补**。
