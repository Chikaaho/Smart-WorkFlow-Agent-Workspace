# P67 · Graph 作为执行器（流程/表单中按入参→出参调用）

日期：2026-11-10｜来源：Owner 补充需求｜状态：未排期｜预估等级：L（跨仓，BPM/表单/智能体三处接入）

## Owner 原话

> graph 可配置为执行器，在流程/表单中使用，来入参->出参供业务使用

## 需求理解

- 已发布的智能体 Graph 可以被流程节点和表单当作一个执行器来调用。
- 调用方配置入参映射（流程变量、表单字段 → Graph 输入），Graph 运行结束后把出参映射回流程变量或表单字段，供后续节点、条件分支或表单展示使用。
- 入参和出参要有明确的结构声明，配置时能选字段，不靠手写字符串。

## 评估时需要定的事项

1. 流程侧的接入方式：新增节点类型，还是作为现有服务/脚本节点的一种执行器（关联 P57 统一节点扩展）。
2. 表单侧的触发时机：字段变化、按钮、加载完成、提交前（关联 P65 表单事件）。
3. 同步还是异步：Graph 运行时间长时流程如何等待、超时和失败怎么处理（重试、走异常分支、人工处理）。
4. 绑定 Graph 的哪个版本：固定版本，还是跟随最新发布版。
5. 权限：以发起人、当前处理人还是系统身份运行；Graph 内能访问的数据范围。
6. 运行记录：每次调用的入参、出参、耗时、结果能否在流程实例里查到。

## 验收方向（排期时细化）

- 在示例流程中配置一个 Graph 执行器节点，入参来自表单，出参驱动条件分支，真实跑通一条实例。
- 在表单中触发一次 Graph 调用，出参回填到字段。
- 超时、Graph 报错、出参缺字段三种情况下流程和表单的表现符合配置。
