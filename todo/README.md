# 暂不修复清单（Won't-Fix Registry）

> 与 `product/`、`knowledge/` 平级的工作区标准目录。本目录另含 **[需求池 requirement-pool.md](requirement-pool.md)**（已开发未满足 + 候选）。本文件只收录"暂不修复"子集，两者互补。
>
> 记录**已有明确决策"当前不投入资源修复"**的已知问题，供未来会话快速判断，避免重复评估同一个已拍板的问题。
>
> 区别于 `knowledge/known-issues.md`：后者记录**全部**已知问题（待修复 / 待设计 / 暂不修复都在），是问题的权威详情来源；本文件只是其中"暂不修复"子集的**决策速查索引**。

## 收录规则

1. 只收录 `known-issues.md` 中已有明确"暂不修复"决策依据的问题（严重程度低 + 有临时方案 / 第三方依赖限制无法修复 / 已明确接受该限制）。
2. 每条必须能追溯到 `knowledge/known-issues.md` 的问题编号，不在本文件复述完整问题描述。
3. 若后续决定修复：从本文件删除该行，并在 `known-issues.md` 中同步更新状态。本文件不做"已完成"标记。
4. 新发现的"决定暂不修复"问题：先在 `known-issues.md` 记录完整详情，再在本文件加一行索引。
