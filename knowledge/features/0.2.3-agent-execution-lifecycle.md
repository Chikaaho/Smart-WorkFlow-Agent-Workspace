## 1. 功能概述

Agent 图执行从"同步阻塞返回"扩展为"异步受理 + 持久事件 + 可取消/可恢复"的生命周期能力：合法请求先返回稳定 executionId（QUEUED），执行结果与增量事件持久化，页面轮询增量显示，支持取消、超时、重启恢复；同步接口契约保留，现有 Web 执行入口切换异步路径。

**DB 迁移**：`V0.2.7__agent_execution_lifecycle.sql`（H2/PG 双份一致；隔离库实测 applied，Flyway 终点 0.2.7）。新增事件表与执行请求表（`sw_agent_graph_execution_event` / `sw_agent_graph_execution_request`），执行表扩展生命周期状态列。

## 2. 生命周期接口（`/api/agent/graph-execution-lifecycle`）

| 端点 | 方法 | 语义 |
|---|---|---|
| `/graphs/{graphId}/executions` | POST | 异步受理：模型/工具完成前先返回 executionId（QUEUED）；受理成功前执行意图已持久记录。支持 `Idempotency-Key` 头：同键同输入回查同一执行，同键冲突输入返回结构化 400；容量满明确拒绝（不无界排队） |
| `/executions/{id}` | GET | 执行详情（持久，跨刷新/重启回查同一执行；终态唯一，输出与记录一致） |
| `/executions/{id}/events?afterSequence=N` | GET | 事件按 sequence 升序 JSON 分页轮询；`afterSequence` 续传只返回更晚事件（有序、无重复、无漏片） |
| `/executions/{id}/cancel` | POST | 取消受理；幂等（重复取消/终态后取消返回成功且不改写结果） |

权限沿既有体系：普通用户只查询/订阅/取消自己发起的执行，管理权限者管理本租户执行，跨租户拒绝；异步线程身份/租户传递不丢失；密钥不进事件、日志或错误。

## 3. 状态机

```
QUEUED → RUNNING → SUCCESS / FAILED
   │        │
   │        └→ CANCEL_REQUESTED → CANCELLED（运行中取消）
   └→ CANCELLED（排队取消，0 副作用）
重启收敛：启动时不确定的 RUNNING / CANCEL_REQUESTED → INTERRUPTED（reason=SERVICE_RESTART），
只重新派发 QUEUED；不盲目自动重放未知副作用的在途执行。
```

**取消语义（可控对端实测）**：排队取消不开始执行（外部执行调用 0 次）；运行取消受理后禁止调度后续节点/新工具调用，外部副作用精确 1 次、`finish(CANCELLED)` 精确 1 次、线程在 5s 界内退出；已完成执行取消不改写结果；已发生外部副作用保留记录，不伪称回滚。

**恢复语义**：服务重启后排队意图受控恢复（重新派发 QUEUED）；在途执行按可证明恢复点处理，无法确认外部效果的标记 INTERRUPTED/SERVICE_RESTART，不重放；界面可解释，无永久 RUNNING 记录。

## 4. 三协议流式与 Key 轮换

- **协议**：OPENAI_CHAT / OPENAI_RESPONSES / ANTHROPIC 三格式均提供真实增量路径（真实 HTTP/SSE 解析，非把完整结果拆字伪装）；未知格式拒绝且不泄漏 Key。可控 HTTP/SSE 对端实测：三格式各自收到真实 delta、聚合文本正确、HTTP 调用各 1 次。
- **失败语义**：首个可见 delta 后流损坏 → 单次请求内报告错误、不重放已输出内容；429 → 客户端报告错误、调用 1 次。
- **两 Key 轮换/冷却**：429 触发 Key 轮换与冷却（`lockedUntil`/`quotaCooldownSeconds`）；**首个可见 delta 之后不再换 Key 重放**（已显示内容/工具副作用不重复）。可控对端轮换测试：`AgentModelRuntimeStreamingRotationTest` 2/2。
- **真实供应商链**：已实测闭合（见 §7 EXT-023-01）。
