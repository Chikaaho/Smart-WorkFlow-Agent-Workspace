# 共享约束（Shared Constraints）

> Engine 通用初始版：本文件承载**当前项目实例**跨 coding 仓库共享的最高优先级工程约束。
> 项目接入后由执行角色按项目实际维护；Engine 不预置任何固定数值、命令或工具栈。

- 当前无项目共享约束（尚未接入具体项目）。

## 声明口径

- 每个工程动作的资源限制（含限内存形式与具体数值）和跨 coding 仓库并发规则，由 `project.md` 与各 coding 仓库工程宪法**针对具体动作**声明；
- 本文件只汇总跨仓库适用的共享结论，不复制各仓库工程宪法正文；
- 未声明的动作，Engine 不推断、不调用；未声明的数值，Engine 不默认。
