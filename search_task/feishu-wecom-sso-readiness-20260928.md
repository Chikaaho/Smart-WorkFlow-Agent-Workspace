# 飞书与企业微信 SSO 聚焦探索

日期：2026-09-28；本会话角色：规划；委派角色：执行。

## 任务目标

利用 Owner 已登录的浏览器核实飞书指定应用与企业微信接入条件，诊断企业微信无法创建应用的实际原因。关联方向：`product/dingtalk-sso/ready/direction-three-provider-sso-20260928.md`。

## 问题与证据

1. 飞书 `https://open.feishu.cn/app/cli_aa30e5e269389cdc/baseinfo`：应用类型、企业归属、凭据是否可取得、必要登录权限、可用范围、回调白名单、发布/生效状态及现有适配器契约差异。正常页面取得必要凭据并存入安全配置，回执只写是否具备。
2. 企业微信 `https://developer.work.weixin.qq.com/`：记录当前产品入口、登录身份类型、企业主体、管理员权限、创建入口及实际错误文字。区分开发者/服务商门户与企业管理后台，通过页面导航与官方说明核实应使用的入口；不要预设创建失败原因。
3. 若可以安全复现创建失败，记录触发动作和脱敏结果；若实际可创建，按主方向授权处理。需主体认证、管理员授权、名额、应用发布或本人交互时明确具体条件、依据和下一动作。
4. 两平台稳定身份字段、企业归属证明、授权/回调/换票要求以各自官方文档核对，列出官方链接和核验时点。检查现有实现差异，避免仅取得凭据便宣称可接入。
5. Owner 允许执行自行决定本地租户与账号；手机号在交接消息中，仅作身份定位线索。回传选定测试环境、租户与账号的脱敏标识及选择依据。
