# 下一功能候选比较探索（2026-08-25）

**本会话角色：规划，委派角色：执行**

## 任务目标

为规划层从未完成候选中选择下一唯一功能，提供结论优先、可比较的现状与风险证据；本任务只探索，不生成需求方向，不实现代码。

## 需要回答的问题

按候选分别回答：

1. 当前候选的准确名称、P/I/M 编号、完成/未完成边界，以及是否已有 `product/*/ready` 或 `passed` 方向；
2. 已有后端/前端/迁移基础与主要缺口，是否存在可直接复用的真实行为链路；
3. 依赖、风险、范围蔓延点和预计是否需要跨后端/前端/迁移；
4. 与其他候选相比，哪个最适合作为下一轮唯一功能，并给出基于事实的排序建议；
5. 如候选信息不足，明确标记“无法从现有材料确认”，不得猜测。

候选至少覆盖：

- M07-F03-03 / F03 知识库 RAG；
- M07 图节点级多 Key 轮询；
- M03/M05 清单中尚未完成且具备明确边界的候选；
- I50（登录状态校验时序）是否应作为独立候选。

## 搜索范围

仅允许读取：

- `knowledge/features/` 中与上述候选直接相关的文件；
- `knowledge/known-issues.md`、`knowledge/current-status.md`、`knowledge/decisions.md`；
- `todo/requirement-pool.md`、`product/*/ready/`、`product/*/passed/` 中与候选直接相关的方向/回执；
- `Smart-WorkFlow/功能清单.md` 中对应 M03/M05/M07 行；
- 必要时读取候选涉及的源码/测试/迁移文件以确认结构和行为基础，但只报告最小必要证据。

## 禁止范围

- 不修改业务代码、测试、迁移或知识库；
- 不运行 `mvn`、`pnpm`、`npm`、数据库迁移、部署或其他状态变更命令；
- 不代替规划层选择需求、不编写需求方向、不拆分 Step、不设计具体测试方案；
- 不把文件存在、类名或测试类名当作行为证据；若未运行验证，只报告静态事实。

## 预期证据

- 每个候选的文件路径与关键位置；
- 已完成基础、缺口和依赖的事实摘要；
- 候选比较表：价值/闭环度/风险/范围/推荐排序；
- 明确推荐一个首选候选及不推荐其他候选的事实原因。

## 完成标准

覆盖全部指定候选，形成单次可读的比较回执；结论与路径证据对应，不把探索结论升级为功能验收结论。

## 失败处理

若某候选材料不存在或无法确认，仍在回执中列出该候选并说明缺失证据，不扩展到无关目录。
