# P45 登录安全现状与接缝探索

> 本会话角色：规划；委派角色：执行。

## 任务目标

为 P45「RSA 密码加密、验证码、客户端时间校验、Cookie 登录态恢复及双 Token 演进骨架」正式需求方向提供最小且可验证的当前实现事实，确认登录、公钥/密钥、验证码、Token/Cookie、前端启动恢复、限流/锁定、日志审计及多实例部署的现有接缝；本任务只探索，不实现、不生成产品方向。

## 需要回答的问题

1. 当前浏览器到后端的登录请求、响应、access/refresh token、Cookie 与异常处理完整链路是什么？分别说明 Token 在响应体、Cookie、内存、`localStorage`、`sessionStorage` 或其他位置的真实去向，Cookie 属性和过期语义，以及页面刷新后丢失登录态的直接原因；请给出前后端字段、入口、调用顺序及真实文件位置。
2. 当前是否已有 RSA/其他应用层密码加密、公钥接口、密钥配置或加解密工具？若有，说明算法参数、密钥来源、生命周期、日志暴露面及是否支持多实例；若无，明确零命中范围。
3. 当前是否已有验证码生成、展示、存储、校验、过期、刷新或一次性消费能力？若只有依赖、SPI、Mock 或空壳，必须与可运行实现分开说明。
4. 当前登录失败限流、账号锁定、IP/账号维度计数、状态校验、审计日志与统一异常映射分别处于什么状态？P25/I50 登录状态校验时序是否仍存在，是否会与 P45 固定校验顺序冲突？
5. 当前 Redis/缓存抽象、数据库或本地内存中，哪一种接缝最适合承载一次性登录挑战；多实例部署下有哪些已有约束？只报告事实与可复用接缝，不替规划层选方案。
6. 当前前端登录页能否承载验证码、公钥版本/挑战标识、客户端时间与验证码刷新交互？现有 API 类型、Mock、错误提示映射和测试接缝是什么？
7. 当前前端应用启动、路由守卫、认证 store、请求层和 `/me`/用户信息读取如何判断登录态？刷新受保护路由为何回到登录页；是否已有恢复入口、401 处理、刷新协调或双 Token 抽象，哪些是真实运行、哪些只是空壳？
8. 现有测试中哪些行为已覆盖登录成功、密码错误、用户状态、Token/Cookie、安全日志、页面刷新恢复、过期失效和退出清理；哪些 P45 必需行为完全缺失？给出测试位置与当前可观察断言，不运行测试。
9. P45 预计影响哪些前后端模块、配置、缓存/迁移与文档表面？明确 Cookie 登录态修复和双 Token 演进接缝的必要影响面，并区分完整 Token 轮换/撤销体系等相邻但不应擅自纳入本轮的范围。

## 搜索范围

- 工作区项目说明与当前状态权威文件（仅为确认仓库职责、当前基线和 P45/P25/I50 状态）。

- 关键字可包括：`login`、`auth`、`password`、`RSA`、`publicKey`、`captcha`、`verifyCode`、`timestamp`、`nonce`、`challenge`、`accessToken`、`refreshToken`、`Cookie`、`Set-Cookie`、`localStorage`、`sessionStorage`、`router`、`guard`、`401`、`Redis`、`rateLimit`、`lock`、`audit`。

## 禁止范围

- 禁止修改任何文件、安装依赖、启动服务、编译、测试、迁移、部署、提交或推送 Git。
- 禁止把旧回执、Mock、接口名或类存在当作当前可运行行为；结论必须回到当前文件事实。
- 禁止替规划层决定产品方向、拆分实施 Step、编写实现代码或扩大到 SSO、MFA、密码策略重构、全站风控。
- 禁止在回执中粘贴密钥、密码、Token、Cookie 或其他敏感值；发现疑似真实密钥时只报告位置和风险，不复制内容。

## 预期证据

- 每个结论至少给出当前文件路径和精确代码位置；零实现结论给出搜索范围与关键字。
- 提供一张「能力/现状/可复用接缝/缺口/证据」矩阵。
- 提供一张当前登录时序摘要，明确密码校验、状态校验、token 签发、异常映射和日志发生顺序。
- 提供一张「登录成功 → Cookie/Token 落点 → 页面刷新 → 状态恢复或跳转 → 过期/退出清理」当前行为链，并指出唯一直接断点。
- 提供 P45 必要影响面与相邻非目标清单，并标注需规划层裁决的真实冲突。

## 完成标准

九个问题全部得到可复核回答；可运行实现、结构空壳、Mock 与零实现严格分层；结论压缩至 5KB 左右，足以让规划角色一次阅读后形成正式方向。
